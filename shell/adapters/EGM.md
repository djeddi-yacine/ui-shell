# adapters

## Overview
QML adapters between the shell UI and external helpers (app2unit, PipeWire helper, settings/theme helper scripts). Helper command paths come from `Config.GeneratedRuntime.commands`; each adapter wraps a `Quickshell.Io` `Process` and exposes state/error properties. Module `UiShell.Adapters` ([adapters/qmldir]).

## Interface
- `AppRunner` [AppRunner.qml:AppRunner]: required `executable`, `launchArguments`; `launch(entry)`, `reportFailure(message, details)`; properties `busy`, `error`, `status`, `output`, `failure`, `failureSequence`; signals `accepted()`, `failed(message)`.
- `AudioGraph` [AudioGraph.qml:AudioGraph]: `active`, `graph`, `ready`, `error`, `command`; `refresh()`, `run(args, key)` (keyed actions coalesce), `next()`.
- `QmlSettingsFile` [QmlSettingsFile.qml:QmlSettingsFile]: required `component`, `scope`, `outputName`; `path`, `revision`, `values`, `mode`, `ready`, `error`, `reading`; `refresh()`, `accept(item)`; signal `settled()`.
- `ComponentSettings` [ComponentSettings.qml:ComponentSettings]: required `component`, `screenName`; `showIcons`, `visibleRows`, `wideColumns`, `maximumVisibleRows`, `ready`, `loading`, `busy`, `loadError`, `saveError`, `failure`; `option(key)`, `value(key, default)`, `sharedValue`, `refresh()`, `save(scope, revision, first, second)`; signals `scopeReady`, `committed`, `failed`.
- `ThemeProfiles` [ThemeProfiles.qml:ThemeProfiles]: required `screenName`; `snapshot`, `snapshotReady`, `busy`, `outputs`, `wallpaperSelection`; `refresh(wallpaperColors)`, `loadProfile(path)`, `reset()`, `readPalette(path)`, `save(id, target, source, mode, colorData, writeDefinition, definitionPath)`; signals `ready`, `paletteReady`, `committed`, `failed`.
- `ControlTuningStore` (singleton) [ControlTuningStore.qml:ControlTuningStore]: `ready`, `busy`, `error`, `revision`; `known(values)`, `reload()`, `save(mode, values)`; signal `saved()`.
- `RecordState` (singleton) [RecordState.qml]: watches the recorder state file with `FileView` (inotify), asks `commands.screenRecord status` for the checked state, exposes `state`, `active`, `elapsed`, `monitors`, `windows`, `cameras`, `audioSources`, `lastRegion`, `picking`, `capabilities`, `start(target, audio, countdown)`, `stop()`, `pickRegion()` and the `failed(failure)`, `regionPicked(region)` and `regionCancelled()` signals for the shared ErrorPopup.
- `ShotRunner` (singleton) [ShotRunner.qml]: `capture(target, { copy, save, delay })` runs `commands.screenShot capture` once and emits `captured(result)` (`{ file, size, copied }`) or `failed(failure)`; `capabilities`, `lastResult`, `busy`. It keeps no state file.
- `PolkitSource` (singleton) [PolkitSource.qml]: the only importer of `Quickshell.Services.Polkit`; owns the `PolkitAgent` (path `/org/quickshell/PolkitAgent`, set once, never bound); exposes `flow` and `agentActive`.
- `PolkitAuth` [PolkitAuth.qml]: polkit logic over an injected `source` (`flow`, `agentActive`); phases `idle|prompt|checking|succeeded|failed|refused` (`succeeded` shows for `successMs` before the dialog closes; the next queued request waits behind it), `displayed` snapshot, `submit`, `cancel`, `selectAccount`, `dismissFailure`. A wrong password ends the request (cancel deferred one event-loop turn) and stays as `failed` until `dismissFailure()`. One request at a time; the module queues the rest. Tested with fakes in `tests/auth/`.
- `MprisSource` (singleton) [MprisSource.qml]: the only importer of `Quickshell.Services.Mpris`; `players`, the module's list without the `playerctld` proxy.
- `MediaSelection` [MediaSelection.qml]: which player the shell controls, on an injected `source.players`; `current` (pin, then the latest playing, then the last that played), `pinKey`, `pinState` (`none|active|absent`), `playerCount`, `keyOf`, and the actions `pin`, `unpin`, `showPlayer`, `playPause`, `pause`, `next`, `previous`, `seekBy`, each gated on the player's own capability. Players with the same key are one entry; state changes are atomic (`current` never shows a wrong player between a change and the bookkeeping); actions drop a call on a player that has quit. Imports nothing relative (it is copied for tests).
- `MediaArt` [MediaArt.qml]: the art logic for the shown player on an injected `runner`: the start-up tool check (`capabilities`), provider steps in order (each step's path feeds the next), debounce, stale guard keyed on (player, mode, address), a hot cache of recent results, `lost(path)`, failure memory, faults once per cause, a cover fallback when blurhash tools are missing (`blurhashAvailable`), `forcedMode` (cover, blurhash or off for every player; auto uses the table); members `state` (`none|loading|ready|failed`), `kind`, `path`, signal `faultReported`. Imports nothing but QtQuick (copied for tests).
- `MediaArtRunner` [MediaArtRunner.qml]: runs one `commands.mediaArt` step at a time as its own process; a killed or replaced run reports nothing; a non-zero exit or unreadable output becomes `tool-failed`.
- `NotifSource` (singleton) [NotifSource.qml]: the only importer of `Quickshell.Services.Notifications`; claims `org.freedesktop.Notifications` through a `NotificationServer` (`keepOnReload`, body markup, hyperlinks, actions, action icons, image, persistence; extra hints `value`, `sound-file`, `sound-name`, `suppress-sound`); signals `received(entry)`, `updated(entry)`, `closed(id)`; `invoke(id, identifier)`, `dismiss(id)`, `toEntry`. Each notification becomes a plain entry (`origin: "dbus"`, `generation` 1 for one replayed after a reload, `progress` clamped to -1..100, urgency as `low|normal|critical`); no Quickshell object leaves the file.

## Invariants
- `AppRunner.launch` ignores calls while `launchPending`; always runs `<executable> <launchArguments> -- <entry.id>.desktop` [AppRunner.qml:launch].
- `AudioGraph` runs one action at a time; `snapshot` output is the sole source of truth, `pw-dump --monitor` only triggers a debounced refresh [AudioGraph.qml:next, debounce, watcher].
- `QmlSettingsFile` accepts a file only when the helper returns exactly two lines: absolute path and revision `absent` or 64-hex; "controls" values must be finite numbers; other components are validated by `Config.ComponentSpec.valid` [QmlSettingsFile.qml:inspect, accept].
- `ComponentSettings.value` precedence: output override, shared default, then configured default; `save` is rejected while `busy` or for scopes other than `default`/`output` [ComponentSettings.qml:value, save].
- `ControlTuningStore.known` drops keys not in `Theme.ControlTuning.schema`; `save` stores only knobs differing from `presetValues(mode)` [ControlTuningStore.qml:known, save].
- `ThemeProfiles` ignores `start`/`loadProfile`/`save` while `busy`; helper reply must be `<absolute path>\n<64-hex revision>` [ThemeProfiles.qml:start, process.onExited].
- RecordState invariants: never reports `recording` from the file alone (the script verifies pid and start time); `elapsed`/`remaining` tick once a second only while a recording is starting or running; one failure per recording [RecordState.qml:shownFailure]. It spawns `commands.screenRecord` (`status`, `capabilities`, `monitors`, `start`, `stop`).
- `NotifSource` forwards every property change of a held notification (summary, body, icon, image, urgency, timeout, actions, hints) as `updated`, because a `replaces_id` or progress update emits no new `notification` signal [NotifSource.qml:onNotification].
- `QmlSettingsFile` for the notifications component validates its `rules` option with `Config.ComponentSpec.validRules` and reports the first problem in `error` (the drawer shows it); the file is read once per `refresh()` and a refresh during a read is queued [QmlSettingsFile.qml:accept, refresh].

## Side Effects
- Spawns `app2unit` via `AppRunner` [AppRunner.qml:runner].
- Spawns `Config.GeneratedRuntime.commands.audioGraph` (`snapshot` and action args) and `pw-dump --monitor --no-colors --indent 0` [AudioGraph.qml:reader, actor, watcher].
- Spawns `commands.readComponentSettings` and `commands.saveComponentSettings`; loads the returned settings file as QML via `file://` Loader [QmlSettingsFile.qml:inspect, qml; ComponentSettings.qml:writer].
- Spawns `commands.readThemeEditor`, `readThemePalette`, `saveThemeProfile`; loads generated native theme data via Loader; on save calls `Theme.ActivePalettes.apply` [ThemeProfiles.qml:process, data, accept].
- `ControlTuningStore` writes component "controls" settings and binds `Theme.ControlTuning.overrides` and `.mode` [ControlTuningStore.qml:Binding, writer].
- Claims the `org.freedesktop.Notifications` bus name for as long as `NotifSource` is loaded; invoking or dismissing acts on the live notification object [NotifSource.qml].
