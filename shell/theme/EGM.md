# theme

## Overview
Theme singletons and control-colour model for the shell: palette, shape, density, typography, motion, interaction math, and a state-driven control colour resolver. Module `UiShell.Theme` ([theme/qmldir]). Prose on palette schema: [README.md](./README.md).

## Interface
- `Style` (singleton) [Style.qml]: global style with `controls` (`ControlColors`), colour roles, shape/density values, `buttonEmphasis`, `primaryActionEmphasis`, `inputEmphasis`, `selectorEmphasis`, `barEntryEmphasis`, etc.; `controlTuning`, `controlMode`.
- `MonitorStyle` [MonitorStyle.qml]: per-output style, required `palette`; optional `controlTuning`, `controlMode`; `controls`.
- `Palette` (singleton) [Palette.qml]: `colorData`, `mode`, `colors`, `hyprland` and 13 role colours, all from `ActivePalettes.globalPalette`.
- `ActivePalettes` (singleton) [ActivePalettes.qml]: `defaultPalette`, `byOutput`, `globalPalette`, `forOutput(name)`, `apply(snapshot, restoresWallpapers)`, signal `profileApplied`.
- `Shape`, `Density`, `Typography`, `Motion` (singletons): read-only constants [Shape.qml, Density.qml, Typography.qml, Motion.qml].
- `Interaction` (singleton) [Interaction.qml]: layer/mix amounts from `ControlTuning.values`; colour functions `luminance`, `mix`, `contrast`, `toOklch`, `fromOklch`, `tonal`, `readable*`, `onFill`, `foreground`.
- `ControlTuning` (singleton) [ControlTuning.qml]: `schema`, `defaults`, `modes`, `mode`, `draftMode`, `activeMode`, `behavior`, `overrides`, `draft`, `values`; `presetValues(key)`.
- `GeneratedControlTuning` (singleton) [GeneratedControlTuning.qml]: `schema`, `vocabulary`, `mode`, `modes`, `values`.
- `ControlColors` [ControlColors.qml]: required `palette`; `tuning`, `mode`, `knobNames`, `tuningValid`, `behavior`, `knob(name, fallback)`, derived role colours.
- `ControlState` [ControlState.qml]: required `colors`, `emphasis`; state flags `enabled`, `hovered`, `pressed`, `selected`, `focused`, `current`; `behavior`, `flags`, `emphasisSpec`.
- `ControlPalette` [ControlPalette.qml]: required `palette`, `colors`; binds Qt palette roles from `colors`.

## Invariants
- `GeneratedControlTuning.qml` header says "Generated by scripts/render-control-tuning. Do not edit."; `ControlTuning` states nothing there is hand-edited [ControlTuning.qml comment].
- `ControlTuning.values` layering order: `defaults`, `overrides`, `draft` [ControlTuning.qml:values].
- `ControlState` throws `Error("ControlState: invalid emphasis ...")` for an emphasis absent from `behavior.emphasis` [ControlState.qml:emphasisSpec].
- `ControlColors` rejects unknown tuning keys via `tuningValid` against `knobNames` [ControlColors.qml:knobNames, tuningValid].
- `ActivePalettes.forOutput` falls back to `defaultPalette` for unknown outputs [ActivePalettes.qml:forOutput].

## Side Effects
- `ActivePalettes.apply` mutates global palette state and emits `profileApplied` [ActivePalettes.qml:apply].
- `ControlPalette` writes Qt palette roles of the target via `Binding` [ControlPalette.qml:bindings].
- `ControlTuning.overrides`/`mode` are bound externally by [../adapters/EGM.md] (`ControlTuningStore`).
- No process, file or network access.
