# gtk2-24: GTK+ 2.24 toolkit (theme engine, rc-file and settings subsystem)

Source: refs/gtk2-24 (shallow clone; commit 6863194; branch gtk-2-24). License: COPYING, GNU Library General Public License v2 (June 1991), cited. Scope: gtk/gtkrc.c, gtk/gtkrc.h, gtk/gtksettings.c, gtk/gtkstyle.c, gtk/gtkstyle.h, gtk/gtkthemes.c, gtk/gtkmodules.c, gtk/gtkenums.h (selected lines), gdk/x11/gdksettings.c, gdk/x11/gdkevents-x11.c (selected lines), modules/engines/pixbuf, modules/engines/Makefile.am. Scope note: the brief names a "pixmap engine". No modules/engines/pixmap directory exists in this tree (checked with git ls-files). The engine studied in its place is modules/engines/pixbuf, the successor that its README describes as based on the older pixmap engine (see GT2.7.1).

Id prefix: GT2.

## 1. Purpose and shape
- GT2.1.1 GTK+ 2.24 is a C widget toolkit. Its theming is a runtime system: rc files and settings are parsed into GtkRcStyle objects, and those are turned into GtkStyle objects that drawing code uses. The core lives in gtk/ and gdk/x11/. `gtk/gtkrc.c:1` (file start), `gtk/gtkstyle.h:73`.
- GT2.1.2 Top-level layout relevant to theming:
  - `gtk/gtkrc.c`, `gtk/gtkrc.h`: rc file parser, rc styles, style lookup. `gtk/gtkrc.c:300-367` (token table).
  - `gtk/gtksettings.c`: GtkSettings properties (theme name, colors, fonts, toolbar options) and their sources. `gtk/gtksettings.c:39`.
  - `gtk/gtkstyle.c`, `gtk/gtkstyle.h`: GtkStyle objects and default draw functions. `gtk/gtkstyle.h:73`.
  - `gtk/gtkthemes.c`: loader for theme engine shared modules. `gtk/gtkthemes.c:61`.
  - `gtk/gtkmodules.c`: GTK module (gtk-modules setting) loader and module search paths. `gtk/gtkmodules.c:55`.
  - `gdk/x11/gdksettings.c`: maps XSettings names to GtkSettings properties. `gdk/x11/gdksettings.c:37-83`.
  - `modules/engines/`: shipped engines. Only `ms-windows` and `pixbuf` are present. `modules/engines/Makefile.am` (SUBDIRS = $(wimp) pixbuf).
- GT2.1.3 Build system: autotools (configure.ac and Makefile.am files). Not studied in detail. See section 8.

## 2. Theme input (how configuration reaches it)
- GT2.2.1 Rc files. Default file list is built in `gtk_rc_add_initial_default_files`, `gtk/gtkrc.c:491-553`. If the environment variable GTK2_RC_FILES is set, it replaces the whole default list (`gtk/gtkrc.c:509`). Otherwise the list is, in order: `$GTK_DATA_PREFIX/share/gtk-2.0/gtkrc` (`gtk/gtkrc.c:528`); `gtk-2.0/gtkrc` in each directory from `g_get_system_config_dirs()` (`gtk/gtkrc.c:532-538`); `GTK_SYSCONFDIR/gtk-2.0/gtkrc` (`gtk/gtkrc.c:540`); `~/.gtkrc-2.0` (`gtk/gtkrc.c:547`).
- GT2.2.2 The per-user XDG path `~/.config/gtk-2.0/gtkrc` is not in the default list. `gtk/gtkrc.c` contains no call to g_get_user_config_dir (checked by reading the list code at `gtk/gtkrc.c:491-553`).
- GT2.2.3 Named theme files. `gtk_rc_parse_named` looks first in `~/.themes/<name>/gtk-2.0/gtkrc`, then in the theme directory, and parses the file at GTK_PATH_PRIO_THEME (`gtk/gtkrc.c:804-852`, priority at line 847). With a type argument the subpath is `gtk-2.0-<type>/gtkrc`. The key theme uses type "key" (`gtk/gtkrc.c:1835`).
- GT2.2.4 Theme directory. `gtk_rc_get_theme_dir` returns `GTK_DATA_PREFIX` (or the compile-time prefix) plus `share/themes` (`gtk/gtkrc.c:460-473`).
- GT2.2.5 Locale variants. `gtk_rc_context_parse_file` also parses `<file>.<lang_COUNTRY>` or `<file>.<lang>` if present, in addition to the base file (`gtk/gtkrc.c:1059-1116`).
- GT2.2.6 Programmatic rc input. `gtk_rc_parse` appends a file to global_rc_files and parses it into every context (`gtk/gtkrc.c:1119-1131`).
- GT2.2.7 Settings sources. GtkSettings property values come from four sources, enumerated by GtkSettingsSource: DEFAULT, RC_FILE, XSETTING, APPLICATION (`gtk/gtksettings.c:50-55`). A stored value is replaced only if the existing source is less than or equal to the new source (`apply_queued_setting`, `gtk/gtksettings.c:1501-1537`).
- GT2.2.8 Read precedence. `gtk_settings_get_property` returns an APPLICATION-sourced value first. Otherwise it asks gdk_screen_get_setting (XSettings); if that returns a value, it overrides the stored value. Otherwise the stored value (rc file or default) is returned (`gtk/gtksettings.c:1303-1381`). Effective order: application, then XSettings, then rc file, then default.
- GT2.2.9 XSettings. The gdk/x11 names table maps XSettings keys to GTK properties, for example Net/ThemeName to gtk-theme-name, Net/IconThemeName, Gtk/ColorScheme to gtk-color-scheme, Gtk/ColorPalette, Gtk/FontName, Gtk/KeyThemeName, Gtk/ToolbarStyle, Gtk/ToolbarIconSize, Gtk/Modules, Gtk/CursorThemeName, Gtk/EnableAnimations, Net/SoundThemeName, and Xft/* (`gdk/x11/gdksettings.c:37-83`; map struct at `gdk/x11/gdksettings.c:90`). Changes arrive through gdk_xsettings_notify_cb (`gdk/x11/gdkevents-x11.c:2942`), and the GTK side reads them in gdk_screen_get_setting (`gdk/x11/gdkevents-x11.c:3021`).
- GT2.2.10 Environment variables read by this code: GTK2_RC_FILES (`gtk/gtkrc.c:509`); GTK_DATA_PREFIX (`gtk/gtkrc.c:460-473`); GTK_PATH and GTK_LIBDIR / GTK_EXE_PREFIX for module search (`gtk/gtkmodules.c:55-100`). Other environment variables appear in these files but were not read individually (see section 8).
- GT2.2.11 Defaults for selected GtkSettings properties (`gtk/gtksettings.c`):
  - gtk-theme-name "Raleigh" (`gtk/gtksettings.c:309-321`, value at 315).
  - gtk-icon-theme-name "hicolor" (`gtk/gtksettings.c:322-329`).
  - gtk-key-theme-name uses DEFAULT_KEY_THEME, which is "Mac" on Quartz builds and NULL otherwise (`gtk/gtksettings.c:39`, `gtk/gtksettings.c:41`, `gtk/gtksettings.c:340-346`).
  - gtk-font-name "Sans 10" (`gtk/gtksettings.c:367-373`).
  - gtk-color-scheme default "" (`gtk/gtksettings.c:580-587`); documented at 554-579.
  - gtk-color-palette default from default_color_palette (`gtk/gtksettings.c:178-180`, spec at 1181-1187).
  - gtk-toolbar-style default GTK_TOOLBAR_BOTH (`gtk/gtksettings.c:1003-1012` parser).
  - gtk-toolbar-icon-size default GTK_ICON_SIZE_LARGE_TOOLBAR (`gtk/gtksettings.c:1018-1027`).
  - gtk-modules (`gtk/gtksettings.c:399`); gtk-cursor-theme-name (`gtk/gtksettings.c:459`); gtk-enable-animations (`gtk/gtksettings.c:590`); gtk-button-images (`gtk/gtksettings.c:1069`); gtk-menu-images (`gtk/gtksettings.c:1106`).
- GT2.2.12 Rc file grammar entry points: `gtk_rc_parse_statement` (`gtk/gtkrc.c:2913-3016`) handles include, style, binding, pixmap_path, widget, widget_class, class, module_path, im_module_file, and top-level property assignments. Assignments are canonicalized with g_strcanon (underscores become dashes) and sent to `_gtk_settings_set_property_value_from_rc` (`gtk/gtkrc.c:2950-2990`).
- GT2.2.13 Include. `parse_include_file` (`gtk/gtkrc.c:2860`) accepts an absolute path, or a relative path resolved against the directories of files on the current parse stack.
- GT2.2.14 Module path directive. `gtk_rc_parse_module_path` ignores the directive and warns "module_path directive is now ignored" (`gtk/gtkrc.c:4140-4155`).

## 3. Color and style model
- GT2.3.1 GtkRcStyle (`gtk/gtkrc.h`). Holds: name; bg_pixmap_name[5]; font_desc; color_flags[5]; fg[5], bg[5], text[5], base[5] as GdkColor; xthickness; ythickness; private rc_properties, rc_style_lists, icon_factories, and an engine_specified bit. Class virtual functions: create_rc_style, parse, merge, create_style.
- GT2.3.2 State index. All color arrays have 5 entries indexed by GtkStateType (NORMAL, ACTIVE, PRELIGHT, SELECTED, INSENSITIVE), defined at `gtk/gtkenums.h:401-405`.
- GT2.3.3 GtkRcFlags. FG = 1<<0, BG = 1<<1, TEXT = 1<<2, BASE = 1<<3 (`gtk/gtkrc.h:52-57`). These mark which colors an rc style has set.
- GT2.3.4 GtkStyle (`gtk/gtkstyle.h:73-123`). Holds fg[5], bg[5], light[5], dark[5], mid[5], text[5], base[5], text_aa[5], black, white, font_desc, xthickness, ythickness, GC arrays per state (fg_gc, bg_gc, light_gc, dark_gc, mid_gc, text_gc, base_gc, text_aa_gc), black_gc, white_gc, bg_pixmap[5], attach_count, depth, colormap, rc_style, styles, property_cache, icon_factories.
- GT2.3.5 Default colors. `gtk/gtkstyle.c:357-368` defines defaults such as normal_fg GTK_BLACK, normal_bg GTK_GRAY, selected_bg GTK_BLUE, selected_base GTK_BLUE, insensitive_fg GTK_WEAK_GRAY. gtk_style_init (`gtk/gtkstyle.c:416`) assigns them (`gtk/gtkstyle.c:442-448`) and sets the default font "Sans 10" (about line 425).
- GT2.3.6 Derived shades. In gtk_style_real_realize (`gtk/gtkstyle.c:1998-2016`): light = shade(bg, 1.3) using LIGHTNESS_MULT; dark = shade(bg, 0.7) using DARKNESS_MULT (defines at `gtk/gtkstyle.c:47-48`); mid = (light + dark) / 2; text_aa = (text + base) / 2.
- GT2.3.7 Shade formula. `_gtk_style_shade` (`gtk/gtkstyle.c:5719-5752`) converts RGB to HLS (rgb_to_hls at `gtk/gtkstyle.c:5753`), multiplies lightness (green channel in the code) and saturation (blue channel) by factor k, clamps each to [0,1], then converts back with hls_to_rgb (`gtk/gtkstyle.c:5824`). rgb_to_hls outputs h, l, s into the r, g, b slots (about `gtk/gtkstyle.c:5818-5820`).
- GT2.3.8 Per-state handling. Color arrays are indexed per state (GT2.3.2). Each state's colors are set separately in rc files with `bg[STATE] = ...` syntax. Parsing: `gtk_rc_parse_state` (`gtk/gtkrc.c:3775-3825`) accepts NORMAL, ACTIVE, PRELIGHT, SELECTED, INSENSITIVE. Sub-state derivation (for example hover or backdrop as separate concepts) is not present; PRELIGHT is the hover-like state.
- GT2.3.9 Color value forms (`gtk_rc_parse_color_full`, `gtk/gtkrc.c:3914-4110`):
  - {r, g, b} with integers 0-65535, or floats scaled by 65535, clamped.
  - A quoted string passed to gdk_color_parse. Invalid input gives the warning "Invalid color constant".
  - @name, a reference to a logical color in the style's color hashes (`lookup_color`, `gtk/gtkrc.c:2498-2515`). Missing names give "Invalid symbolic color".
  - mix(f, c1, c2): per channel f*c1 + (1-f)*c2 (about `gtk/gtkrc.c:4000-4030`).
  - shade(f, c) calls _gtk_style_shade with factor f; lighter(c) uses 1.3 and darker(c) uses 0.7 (about `gtk/gtkrc.c:4050-4080`).
- GT2.3.10 Logical colors. `color "name" = <value>` inserts a copy into the rc style's color hash (`gtk_rc_parse_logical_color`, `gtk/gtkrc.c:4581-4620`).
- GT2.3.11 Thickness and font. xthickness and ythickness are integers (`gtk/gtkrc.c:3399`, `gtk/gtkrc.c:3417`). font_name is parsed by pango_font_description_from_string (`gtk/gtkrc.c:3608-3634`). The keywords `font` (`gtk/gtkrc.c:3562-3584`) and `fontset` (`gtk/gtkrc.c:3585-3607`) are parsed and ignored.
- GT2.3.12 Color-scheme (gtk-color-scheme). It is a string of "name: color" lines (gtk-color-scheme docs at `gtk/gtksettings.c:554-579`). `settings_update_color_scheme` (`gtk/gtksettings.c:2415-2436`) reads it as XSETTING source. `add_color_to_hash` (`gtk/gtksettings.c:2438-2453`) and `add_colors_to_hash_from_string` (`gtk/gtksettings.c:2456-2500`) parse entries: the name is the text before ':' (no trimming seen in the code), the value after the spaces up to newline or ';' is passed to gdk_color_parse, and invalid colors are skipped. `update_color_hash` (about `gtk/gtksettings.c:2503-2600`) merges rc sources and replaces the table for other sources. `merge_color_scheme` (about `gtk/gtksettings.c:2602`), `get_color_hash` (about `gtk/gtksettings.c:2625`), `append_color_scheme` (`gtk/gtksettings.c:2638-2648`, writes "name: #rrrrggggbbbb\n"), and `get_color_scheme` (`gtk/gtksettings.c:2651`).
  - UNVERIFIED: whether @name references in rc files are resolved against gtk-color-scheme colors. The color hashes are attached to styles by gtk_rc_style_append_color_hashes (called from gtk_rc_init_style), but the full call path was not read.
- GT2.3.13 Color-scheme is a settings property with no light/dark mode switch in this version. No dark-mode or prefers-color-scheme logic was found in gtk/ (a search of the settings and style files was done; not exhaustive, see section 8).
- GT2.3.14 Style merge rules. gtk_rc_style_real_merge (`gtk/gtkrc.c:1418-1477`): for each state, the first-set fg, bg, text, and base win; thickness is applied if it is less than 0 (unset); font is merged; rc properties are merged.

## 4. Output and rendering path
Call chain from configuration to pixels, in order:

- GT2.4.1 Startup. gtk_rc_add_initial_default_files builds the default file list (`gtk/gtkrc.c:491-553`). Each rc file is parsed by gtk_rc_parse_statement (`gtk/gtkrc.c:2913-3016`).
- GT2.4.2 Style blocks. `style "name" = "parent" { ... }` is parsed by gtk_rc_parse_style (`gtk/gtkrc.c:3019-3305`). A parent copies colors, thickness, font, pixmap names, and rc properties. Block items: bg, fg, text, base (with state brackets, parsed at `gtk/gtkrc.c:3307`, `3330`, `3353`, `3376`), xthickness, ythickness, bg_pixmap (`gtk/gtkrc.c:3435-3490`; special values "<parent>" and "<none>"), font_name, engine, stock, color, and Type::property = value (typed rc properties through insert_rc_property).
- GT2.4.3 Binding rules. `widget`, `widget_class`, and `class` statements bind a style to a pattern (`gtk_rc_parse_path_pattern`, `gtk/gtkrc.c:4178-4290`). The style named must already exist, otherwise a parse error results. Widget rc sets go to context->rc_sets_widget and the similar arrays for class patterns.
- GT2.4.4 Priorities. Enum at `gtk/gtkenums.h:287-292`: LOWEST 0, GTK 4, APPLICATION 8, THEME 10, RC 12, HIGHEST 15. Priority is parsed by gtk_rc_parse_priority (`gtk/gtkrc.c:3826-3889`). Default priority for parsed rc is GTK_PATH_PRIO_RC (`gtk/gtkrc.c:731`).
- GT2.4.5 Reparse trigger. Signal hookups (`gtk/gtkrc.c:713-726`): notify::gtk-theme-name and notify::gtk-key-theme-name call gtk_rc_settings_changed (about `gtk/gtkrc.c:638-662`), which reparses when either name changes; notify::gtk-font-name calls gtk_rc_font_name_changed (`gtk/gtkrc.c:664`); notify::color-hash calls gtk_rc_color_hash_changed (`gtk/gtkrc.c:673-683`), which reparses.
- GT2.4.6 Full reparse. gtk_rc_reparse_all_for_settings (`gtk/gtkrc.c:1760-1852`), run on force or mtime change: clears styles, resets rc-sourced settings, clears rc files, parses the default files, then global_rc_files, then the theme name (`gtk/gtkrc.c:1833`) and the key theme (`gtk/gtkrc.c:1835`), then gtk_rc_reset_widgets.
- GT2.4.7 Style lookup. gtk_rc_get_style (`gtk/gtkrc.c:1958-2030`) matches context->rc_sets_widget (by gtk_widget_path), rc_sets_widget_class (by gtk_widget_class_path), and rc_sets_class (walking GType parents). Matches are sorted (sort_and_dereference_sets) and a per-widget rc style may be stored in qdata "gtk-rc-style". If nothing matches, the default style is used.
- GT2.4.8 Style construction. gtk_rc_init_style (`gtk/gtkrc.c:2411-2495`) caches by the list of rc styles. The base style is the first engine_specified or non-base-type rc style. A proto style is created with create_rc_style and merged with all matched styles. "<none>" background pixmap is cleared. Then gtk_rc_style_to_style (`gtk/gtkrc.c:2394-2405`) calls create_style, _gtk_style_init_for_settings, and init_from_rc.
- GT2.4.9 Font setup. _gtk_style_init_for_settings (`gtk/gtkstyle.c:393-410`) reads the default font name from settings, parses it with pango_font_description_from_string, and substitutes "Sans" and size 10 with warnings if the family or size is missing.
- GT2.4.10 Copy into GtkStyle. gtk_style_real_init_from_rc (`gtk/gtkstyle.c:1707-1734`) copies rc colors for states whose color_flags are set, and thickness if it is 0 or more.
- GT2.4.11 Attach and realize. gtk_style_attach (`gtk/gtkstyle.c:720` onward) creates per-colormap clones and realizes on first attach; gtk_style_real_realize (`gtk/gtkstyle.c:1998-2016`) computes derived shades (GT2.3.6) and allocates GCs.
- GT2.4.12 Widget attach. gtk_widget_ensure_style (`gtk/gtkwidget.c:6577-6584`) calls gtk_widget_reset_rc_style (`gtk/gtkwidget.c:6588-6609`), which calls gtk_rc_get_style, falls back to gtk_widget_get_default_style, then gtk_widget_set_style_internal (`gtk/gtkwidget.c:6969`).
- GT2.4.13 Drawing. Public gtk_paint_* functions dispatch to the style class. gtk_paint_box (`gtk/gtkstyle.c:6191-6206`) calls klass->draw_box. The prototype for gtk_paint_box is at `gtk/gtkstyle.h:710-720`. The GtkStyleClass vtable (`gtk/gtkstyle.h:125-429`) has draw slots for hline, vline, shadow, polygon, arrow, diamond, box, flat_box, check, option, tab, shadow_gap, box_gap, extension, focus, slider, handle, expander, layout, resize_grip, spinner, and string, plus realize, unrealize, copy, clone, init_from_rc, set_background, render_icon (`gtk/gtkstyle.h:133-406`).
- GT2.4.14 Default draw functions are the built-in gtk_default_draw_* set in gtk/gtkstyle.c. Their bodies were not read (see section 8).
- GT2.4.15 No CSS, SVG, or generated theme file output is used in this version. Images are PNG or other gdk-pixbuf formats loaded from pixmap paths (see GT2.4.16 and section 5).
- GT2.4.16 Pixmap lookup. gtk_rc_find_pixmap_in_path (`gtk/gtkrc.c:3505-3553`) searches the context pixmap_path first, then the directories of files on the parse stack. A missing file gives "Unable to locate image file in pixmap_path". gtk_rc_parse_pixmap_path (`gtk/gtkrc.c:4112-4139`) splits the string on G_SEARCHPATH_SEPARATOR and replaces the previous list.

## 5. Extension and integration points
- GT2.5.1 Theme engine modules (`gtk/gtkthemes.c`). An engine is a shared library found by gtk_rc_find_module_in_path (`gtk/gtkrc.c:3556-3559`), which calls _gtk_find_module(name, "engines"). gtk_theme_engine_load (`gtk/gtkthemes.c:61-108`) opens it with g_module_open (LAZY | LOCAL). It requires the symbols theme_init, theme_exit, and theme_create_rc_style, and calls theme_init(module). gtk_theme_engine_unload (`gtk/gtkthemes.c:110-120`) calls exit and closes the module. gtk_theme_engine_get (`gtk/gtkthemes.c:161-185`) caches engines by name and uses g_type_module_use; it returns NULL on failure. gtk_theme_engine_create_rc_style (`gtk/gtkthemes.c:188-191`).
- GT2.5.2 The rc grammar hands the engine block to the engine. gtk_rc_parse_engine (`gtk/gtkrc.c:3635-3772`): `engine "" { }` marks a built-in engine (engine_specified bit); `engine "name" { ... }` calls gtk_theme_engine_get and then the engine's rc class parse. If the engine cannot be loaded, the block is skipped by brace counting.
- GT2.5.3 Module search path (`gtk/gtkmodules.c`). get_module_path (`gtk/gtkmodules.c:55-100`) builds the list from GTK_PATH entries, then ~/.gtk-2.0, then GTK_LIBDIR/gtk-2.0 (or GTK_EXE_PREFIX/lib/gtk-2.0). _gtk_get_module_path (`gtk/gtkmodules.c:111-140`) expands each entry to four variants: path/GTK_BINARY_VERSION/GTK_HOST/type, path/GTK_BINARY_VERSION/type, path/GTK_HOST/type, path/type. _gtk_find_module (`gtk/gtkmodules.c:188` onward) returns an absolute name as is; otherwise it builds a g_module path or a libtool .la path in each directory.
- GT2.5.4 Engine directory used by rc parsing: gtk_rc_get_module_dir returns gtk_rc_make_default_dir("engines") (`gtk/gtkrc.c:486-488`). gtk_rc_make_default_dir (`gtk/gtkrc.c:394-406`) uses GTK_EXE_PREFIX or GTK_LIBDIR, plus gtk-2.0, plus GTK_BINARY_VERSION.
- GT2.5.5 GTK modules (gtk-modules setting). Read at `gtk/gtksettings.c:399` and `gtk/gtkmodules.c:462`; gdk_screen_get_setting at `gtk/gtkmodules.c:496-499`; _gtk_modules_init at `gtk/gtkmodules.c:511-545`; _gtk_modules_settings_changed at `gtk/gtkmodules.c:562-575`.
- GT2.5.6 Engine ABI. The engine API surface is the GtkRcStyle class (`gtk/gtkrc.h`) and GtkStyle (`gtk/gtkstyle.h`). The engine module is loaded with g_module_open (`gtk/gtkthemes.c:61-108`); how the headers are installed was not checked (see section 8). The GTK binary version string (GTK_BINARY_VERSION) is part of the search path (GT2.5.3), so modules are version-scoped by directory. Soname and private-header details were not checked (see section 8).
- GT2.5.7 Module-level hook: a GTK module shared library is loaded by name from gtk-modules; its entry points were not read (see section 8).
- GT2.5.8 Environment selection: an engine is chosen by name in rc (`engine "name"`), not by environment variable. The environment variables that affect discovery are listed in GT2.2.10.

## 6. Data and tooling
- GT2.6.1 Theme file format: plain-text rc files (gtkrc), parsed by a GScanner-based grammar (`gtk/gtkrc.c`, token table at `gtk/gtkrc.c:300-367`). Tokens include include, normal, active, prelight, selected, insensitive, fg, bg, text, base, xthickness, ythickness, font, fontset, font_name, bg_pixmap, pixmap_path, style, binding, bind, widget, widget_class, class, lowest, gtk, application, theme, rc, highest, engine, module_path, stock, im_module_file, LTR, RTL, color, unbind.
- GT2.6.2 Built-in default rc. _gtk_rc_init (`gtk/gtkrc.c:866` onward) holds a built-in RC string defining styles such as gtk-default-tooltips-style, progress-bar, entry, menu-item, menu-bar-item, label, and class, widget, and widget_class rules.
- GT2.6.3 Stock and icon source grammar is in gtk/gtkrc.c (`gtk/gtkrc.c:4292-4506` icon source, `gtk/gtkrc.c:4507` onward stock). Not read in detail.
- GT2.6.4 Theme directories in the shared tree: none were enumerated by this study (no theme data is shipped in refs/gtk2-24 beyond what is in the source tree; not checked).
- GT2.6.5 Tests and generators: not studied (see section 8).

## 7. Facts of note
- GT2.7.1 modules/engines/pixbuf README (16 lines, by Owen Taylor, dated 6 Feb 2000) states the engine is based on the older pixmap engine and that "There are lots of bugs here, a considerable number of bugs". `modules/engines/pixbuf/README:1-16`.
- GT2.7.2 Pixbuf engine structure. pixbuf-main.c registers PixbufRcStyle and PixbufStyle (theme_init), has an empty theme_exit, creates the rc style in theme_create_rc_style, and checks the GTK version in g_module_check_init (`modules/engines/pixbuf/pixbuf-main.c`; function names as read).
- GT2.7.3 Pixbuf rc grammar. The engine's rc-style parse (pixbuf_rc_style_parse, `modules/engines/pixbuf/pixbuf-rc-style.c:829-896`) accepts only `image { ... }` at top level under scope "pixbuf_theme_engine"; other tokens are skipped. theme_parse_image (about `modules/engines/pixbuf/pixbuf-rc-style.c:676-826`) reads attributes inside the block: image, function, file, stretch, recolorable, border, detail, state, shadow, gap_side, gap_file, gap_border, gap_start_file, gap_start_border, gap_end_file, gap_end_border, overlay_file, overlay_border, overlay_stretch, arrow_direction, orientation, direction, expander_style, window_edge (token table about `modules/engines/pixbuf/pixbuf-rc-style.c:46-69`).
- GT2.7.4 Function names. theme_symbols (`modules/engines/pixbuf/pixbuf-rc-style.c:44-110`) maps names to draw functions: HLINE, VLINE, SHADOW, POLYGON, ARROW, DIAMOND, OVAL, STRING, BOX, FLAT_BOX, CHECK, OPTION, CROSS, RAMP, TAB, SHADOW_GAP, BOX_GAP, EXTENSION, FOCUS, SLIDER, ENTRY, HANDLE, STEPPER, EXPANDER, RESIZE_GRIP. theme_parse_function (`modules/engines/pixbuf/pixbuf-rc-style.c:344-362`) sets the function only if the token is in the function range; other tokens are silently ignored.

- GT2.7.7 Matching. match_theme_image (`modules/engines/pixbuf/pixbuf-draw.c:38-101`) selects an image by function, then by THEME_MATCH flags (`modules/engines/pixbuf/pixbuf.h:135-142`: GAP_SIDE, ORIENTATION, STATE, SHADOW, ARROW_DIRECTION, EXPANDER_STYLE, WINDOW_EDGE, DIRECTION), then by detail string equality.
- GT2.7.8 Draw overrides.
