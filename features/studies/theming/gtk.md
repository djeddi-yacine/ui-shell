# gtk: GTK 4 toolkit, theming machinery only (CSS providers, settings, theme lookup, built-in Adwaita-style "Default" theme)

Source: refs/gtk (shallow clone; commit e47186d 2026-11-12; branch main). License: COPYING (GNU Library General Public License, version 2 text; per-file headers are not re-checked here). Scope: gtk/gtkcssprovider.c, gtk/gtksettings.c, gtk/gtksettingsprivate.h, gtk/gtkstyleprovider.h, gtk/gtkstyleprovider.c, gtk/gtkcssnode.c, gtk/gtkcssselector.c, gtk/gtkcsscolorvalue.c, gtk/gtkcsscolor.c, gtk/gtkdebug.c, gtk/css/ (parser entry points only), gtk/theme/Default/, gtk/theme/Empty/, gdk/wayland/gdksettings-wayland.c, gdk/x11/gdksettings.c, gdk/gdkhsla.c. Widget, rendering (GSK), and inspector internals are out of scope.
Id prefix: G4

## 1. Purpose and shape
- G41.1 GTK 4 is a C toolkit (GObject-based). Its CSS styling engine is implemented in gtk/gtkcss*.c and gtk/css/. The public provider object is `GtkCssProvider`; it parses CSS-like input into per-selector rule sets. `gtk/gtkcssprovider.c:60-88` (class doc describing the provider and the automatic theme files it loads at init).
- G41.2 Theming-relevant directories:
  - `gtk/gtkcssprovider.c`: provider object, theme file search, `gtk_css_provider_load_named`, `@define-color` parsing.
  - `gtk/gtksettings.c`: `GtkSettings` properties, settings.ini loader, theme-name resolution, binding to the color-scheme and contrast properties.
  - `gtk/gtkstyleprovider.h`: priority constants for the style cascade.
  - `gtk/gtkcssnode.c`, `gtk/gtkcssselector.c`: CSS node tree and selector matching (state pseudo-classes, first-child, etc.).
  - `gtk/gtkcsscolorvalue.c`, `gtk/gtkcsscolor.c`: color values and color functions.
  - `gtk/css/`: tokenizer, parser, location and section types.
  - `gtk/theme/Default/`: built-in theme sources (SCSS) and the pre-generated gtk.css wrapper.
  - `gtk/theme/Empty/gtk.css`: empty built-in theme.
  - `gdk/wayland/gdksettings-wayland.c`, `gdk/x11/gdksettings.c`: backends that push system settings into GtkSettings.
- G41.3 Build: meson (`meson.build` at the repo root; `gtk/meson.build:739-756` generates `gtk.gresources.xml` through `gen-gtk-gresources-xml.py`). The Default theme is compiled by `gtk/theme/Default/meson.build:1-35`.

## 2. Theme input (how configuration reaches it)
- G42.1 Startup CSS files (read by GTK itself, in this order per the class doc). `$XDG_CONFIG_HOME/gtk-4.0/gtk.css` (user override, added at USER priority, see G42.7), then the first existing `THEME/gtk-VERSION/gtk-VARIANT.css` among `$XDG_DATA_HOME/themes`, `$HOME/.themes`, `$XDG_DATA_DIRS/themes`, and `DATADIR/share/themes`. `gtk/gtkcssprovider.c:72-86`.
- G42.2 Version fallback inside a theme directory: `gtk-4.N` directories are searched from the current minor version downward in steps of 2, down to `gtk-4.0`. `gtk/gtkcssprovider.c:1859-1866` (comment), `1867-1901` (`_gtk_css_find_theme_dir`).
- G42.3 Lookup order implemented by `_gtk_css_find_theme`: user data dir (`g_get_user_data_dir()`, subdir `themes`), then `$HOME/.themes` (logs a deprecation debug message under GTK_DEBUG=css), then each `g_get_system_data_dirs()` entry under `themes`, then the built-in data dir. `gtk/gtkcssprovider.c:1907-1948`.
- G42.4 Built-in data dir: `_gtk_get_theme_dir()` returns `$GTK_DATA_PREFIX/share/themes` if the env var is set, else the compiled data prefix plus `share/themes`. `gtk/gtkcssprovider.c:1831-1839`.
- G42.5 Named theme loading: `gtk_css_provider_load_named (provider, name, variant)`. It first checks for an embedded resource `/org/gtk/libgtk/theme/NAME/gtk-VARIANT.css` (or `.../NAME/gtk.css` when variant is empty). If absent, it searches the file locations in G42.3. If the file is found, it also registers `gtk.gresource` from the same directory when present. Fallbacks: names `HighContrast`, `HighContrastInverse`, `Adwaita-dark` map to the Default theme variants; any other unknown name falls back to Default with the same variant. `gtk/gtkcssprovider.c:1967-2064` (resource path at 2001-2004; fallbacks at 2045-2063). This function is marked deprecated since 4.20 in its doc comment (`gtk/gtkcssprovider.c:1952-1966`).
- G42.6 Variant encoding: a variant string containing `dark` sets prefers-color-scheme to DARK, otherwise LIGHT; a variant containing `hc` sets prefers-contrast to MORE. Empty variant sets DEFAULT. `gtk/gtkcssprovider.c:1981-1995`.
- G42.7 `settings_init_style` builds the theme provider (bound to `gtk-interface-color-scheme`, `gtk-interface-contrast`, `gtk-interface-reduced-motion`) and adds it to the cascade at SETTINGS priority (`gtk/gtksettings.c:1219-1225`). A second provider (bound to the same three properties) loads `$XDG_CONFIG_HOME/gtk-4.0/gtk.css` if it is a regular file, and is added at USER priority (`gtk/gtksettings.c:1194-1217`). Init function starts at `gtk/gtksettings.c:1166`.
- G42.8 Theme name resolution, `get_theme_name`: (a) env var `GTK_THEME` wins; a trailing `:VARIANT` after the last colon is taken as the variant (e.g. `GTK_THEME=Name:dark`). (b) otherwise the `gtk-theme-name` property (default `DEFAULT_THEME_NAME` = "Default", `gtk/gtksettingsprivate.h:25`, `gtk/gtksettings.c:407-410`). The variant is `hc-dark`, `hc`, or `dark` from the theme provider's prefers-contrast and prefers-color-scheme; empty otherwise. `gtk/gtksettings.c:1726-1785`; env read at 1737-1738.
- G42.9 Per-theme settings.ini: after the theme CSS loads, `$THEME_DIR/settings.ini` is read with source GTK_SETTINGS_SOURCE_THEME. `gtk/gtksettings.c:1787-1810` (path at 1804-1805).
- G42.10 Global settings.ini files, loaded at GtkSettings init, in increasing precedence: `DATADIR/share/gtk-4.0/settings.ini`, `SYSCONFDIR/gtk-4.0/settings.ini`, each `$XDG_CONFIG_DIRS/gtk-4.0/settings.ini`, then `$XDG_CONFIG_HOME/gtk-4.0/settings.ini`. `gtk/gtksettings.c:287-304`. Parser: `gtk_settings_load_from_key_file` at `gtk/gtksettings.c:1833` (reads `[Settings]` keys and sets GtkSettings properties through their GParamSpec types).
- G42.11 Default property values come from the GParamSpec defaults; `settings.ini` overrides them with source DEFAULT. `gtk/gtksettings.c:280-286`.
- G42.12 System backends push values into GtkSettings. Wayland: the `org.freedesktop.portal.Settings` D-Bus portal is queried (`PORTAL_SETTINGS_INTERFACE` at `gdk/wayland/gdksettings-wayland.c:440`; proxy creation at 455-470, patterns `org.gnome.*` and `org.freedesktop.appearance`). If the portal is unavailable or the GDK debug flag `GDK_DEBUG_DEFAULT_SETTINGS` is set, the code uses fallback defaults (see G42.13). Lookup table `translations[]` at `gdk/wayland/gdksettings-wayland.c:269-313` maps (schema, key) pairs to GtkSettings property names. X11: XSettings client, with table `gdk/x11/gdksettings.c:25-62` (XSettings names such as `Net/ThemeName`, `Gtk/FontName`, `Gtk/DecorationLayout`).
- G42.13 Wayland fallback defaults, `gdk/wayland/gdksettings-wayland.c:269-313`: `org.gnome.desktop.interface gtk-theme` -> `gtk-theme-name` default "Adwaita"; `icon-theme` -> `gtk-icon-theme-name` default "gnome"; `font-name` -> `gtk-font-name` default "Adwaita Sans 11"; `enable-animations` -> `gtk-enable-animations` default TRUE; `org.gnome.desktop.wm.preferences button-layout` -> `gtk-decoration-layout` default "menu:close"; `org.freedesktop.appearance color-scheme` -> `gtk-interface-color-scheme` default 0; `contrast` -> `gtk-interface-contrast`; `reduced-motion` -> `gtk-interface-reduced-motion`; `accent-color` -> `gtk-accent-color` (default RGBA 0,0,0,1). Note: the literal defaults in the table are values the code passes when the key is missing; they are not the GtkSettings GParamSpec defaults.
- G42.14 Mapping of the portal `color-scheme` value: `gdk/wayland/gdksettings-wayland.c:360` (special-cased key compare). The enum to value mapping is in the translation code around lines 318-360 and was not fully read (UNVERIFIED: exact integer-to-enum mapping).
- G42.15 X11 settings mapping (XSettings names to GtkSettings properties) in `gdk/x11/gdksettings.c:31-62`. Includes `Gtk/ColorScheme` -> `gtk-color-scheme` (a separate, non-enum property name) and `Gtk/DecorationLayout` -> `gtk-decoration-layout`.
- G42.16 Settings gsettings-based reads in GTK itself are limited to the debug schema `gtk/org.gtk.gtk4.Settings.Debug.gschema.xml`; theme properties are not read from gsettings by `gtk/gtksettings.c`. Theme-relevant gsettings are read by the GDK backend (G42.12-G42.13).
- G42.17 Deprecated property: `gtk-application-prefer-dark-theme` is still a property. Setting it maps to `gtk-interface-color-scheme` (DARK or LIGHT) and emits a g_warning ("Use GtkSettings:gtk-interface-color-scheme instead"). `gtk/gtksettings.c:739-760` (doc and pspec), `gtk/gtksettings.c:1335-1350` (set path).
- G42.18 Environment variables read for theming and debugging: `GTK_THEME` (G42.8), `GTK_DATA_PREFIX` (G42.4), `GTK_DEBUG` (parsed by `gdk_parse_debug_var` at `gtk/gtkdebug.c:155-156`; flag table `gtk_debug_keys` at `gtk/gtkdebug.c:123-150`). Notable flags: `css` (deprecated CSS feature info, `gtk/gtkdebug.c:144`), `no-css-cache` (disables style property cache, `gtk/gtkdebug.c:137`), `interactive` (enables the GTK inspector, `gtk/gtkdebug.c:138`), `snapshot`, `svg-errors`. `GTK_DEBUG` is also read directly in gtk/gtksettings.c:1983 (context not studied).
- G42.19 Other GtkSettings properties that affect appearance (declared in gtk/gtksettings.c): `gtk-icon-theme-name` (pspec at 419), `gtk-font-name` (433-441), `gtk-xft-antialias`/`-hinting`/`-hintstyle`/`-rgba`/`-dpi` (444-500), `gtk-hint-font-metrics` (503-514), `gtk-cursor-theme-name` (517-525), `gtk-enable-animations` (561-567), `gtk-decoration-layout` (832-857, default "menu:minimize,maximize,close" at 855-857), `gtk-interface-color-scheme` (1003-1016, default UNSUPPORTED), `gtk-interface-contrast` (1020-1033), `gtk-interface-reduced-motion` (1037-1050). Not studied in detail: `gtk-key-theme-name`, `gtk-cursor-theme-size`.

## 3. Color and style model
- G43.1 Named colors: `@define-color NAME VALUE;` is parsed by `parse_color_definition` (`gtk/gtkcssprovider.c:1143-1180` region). The value is parsed with `gtk_css_color_value_parse`; the result is stored in the provider's `symbolic_colors` hash table keyed by name. Missing semicolon is a syntax error. `gtk/gtkcssprovider.c:1143-1175`.
- G43.2 Named color references in property values are resolved through the symbolic color table of the providers in the cascade (lookup code not read; UNVERIFIED: exact lookup function name).
- G43.3 Color value kinds: `gtk/gtkcsscolorvalue.c` holds the color value types. Constructors: `gtk_css_color_value_new_shade` (line 1028), `gtk_css_color_value_new_alpha` (1055), `gtk_css_color_value_new_mix` (1122), `gtk_css_color_value_new_color_mix` (declared at 42; definition not re-read). The `shade` and `alpha` members hold `color` and `factor` (`gtk/gtkcsscolorvalue.c:1048-1049` for shade). The member union declaring `shade`/`alpha` is around line 93 (`gtk/gtkcsscolorvalue.c:93`).
- G43.3a Named color references: `gtk_css_color_value_parse` (`gtk/gtkcsscolorvalue.c:1982`) accepts an `@`-keyword token as a named-color reference and emits a deprecation warning ("@define-color and named colors are deprecated") at `gtk/gtkcsscolorvalue.c:1993-1995`. The lookup body after the warning was not read (UNVERIFIED: exact lookup call).
- G43.4 Shade formula. `apply_shade` (`gtk/gtkcsscolorvalue.c:567-575`) converts RGBA to HSLA and calls `_gdk_hsla_shade`. `_gdk_hsla_shade` (`gdk/gdkhsla.c:163-179`) keeps hue, multiplies lightness by factor, clamps to [0,1]; multiplies saturation by factor and clamps to [0,1]; copies alpha unchanged (`dest->alpha = src->alpha`, line 178).
- G43.5 Color functions parsed by `gtk_css_color_value_parse` (`gtk/gtkcsscolorvalue.c`, function at 1982):
  - `lighter(c)`: shade by 1.3 (deprecated, `gtk/gtkcsscolorvalue.c:2108-2121`).
  - `darker(c)`: shade by 0.7 (deprecated, `2122-2135`).
  - `shade(c, f)`: shade by f (deprecated, `2136-2149`).
  - `alpha(c, f)`: alpha factor (deprecated, `2150-2163`).
  - `mix(c1, c2, f)`: linear mix (deprecated, `2164-2180`).
  - `rgb()`/`rgba()` at 2002, `hsl()`/`hsla()` at 2018, `color-mix()` at 2083. The list of recognized function names is at `gtk/gtkcsscolorvalue.c:1166-1179`.
  - When no function or named color matches, the fallback is `gdk_rgba_parser_parse` (end of the parse function; CSS named colors such as `red` come from there, not verified in the GDK parser).
- G43.6 Relative-color syntax used by the Default theme (for example `hsl(from #{$fg_color} h calc(s * 1.8) calc(l * 1.8))` and `rgb(from black r g b / calc(alpha * 0.35))`) is evident in `gtk/theme/Default/_colors-public.scss:96-105`, so the parser accepts the `from` form. Handling of the `from` keyword in code was not separately read (UNVERIFIED: file and line of the relative-color parser).
- G43.7 Light and dark: the color scheme is not a separate palette in the CSS model. The Default theme handles it by compiling separate variant files (light, dark, hc, hc-dark) from SCSS with `$variant` and `$contrast` variables (`gtk/theme/Default/Default-light.scss:1-13`). At runtime the choice is made by media queries in the wrapper gtk.css (G44.4).
- G43.8 Style properties per node: `gtk/gtkcssnode.c` holds the node tree and state flags. `gtk_css_node_get_style` (`gtk/gtkcssnode.c:1005`), `gtk_css_node_set_name` (1085), `gtk_css_node_set_state` (1119), `gtk_css_node_validate` (1364), `gtk_css_node_get_style_provider` (1389). Widget CSS names are set with `gtk_widget_class_set_css_name` (e.g. `gtk/gtkbutton.c:331` sets "button"; base class sets "widget" at `gtk/gtkwidget.c:1985`).
- G43.9 State pseudo-classes supported in selectors (`gtk/gtkcssselector.c:1323-1334`): `active` (1323), `hover` (1324, maps to GTK_STATE_FLAG_PRELIGHT), `checked` (1332), `backdrop` (1329), `focus-visible` (1333), and others in the same table (the table was read only through line 1334). Insensitive state is mapped from GTK_STATE_FLAG_INSENSITIVE (`gtk/gtkcssnode.c:1138`).
- G43.10 Structural pseudo-classes: `first-child`, `last-child`, `only-child` (`gtk/gtkcssselector.c:1319-1322`).
- G43.11 In the Default theme, hover/pressed/disabled/backdrop variations are written as CSS rules in the SCSS sources (`gtk/theme/Default/_common.scss`, not read in detail); the C side tracks the state flags (G43.9) and does not compute per-state shades.

## 4. Output and rendering path
- G44.1 Input to pixels, in order:
  1. `gtk_css_provider_load_from_*` (`gtk/gtkcssprovider.c:1650` data, `1735` file, `1782` path, `1808` resource) parses text through `gtk/css/gtkcssparser.c` (the parser lives under gtk/css/; entry points were not individually read).
  2. `@define-color` entries are stored in the provider (G43.1). `@import url("resource://...")` is used by the Default wrapper (G44.4); the import handler itself was not read (UNVERIFIED).
  3. Rule selectors are matched against `GtkCssNode` trees (`gtk/gtkcssselector.c` `gtk_css_selector_match_one` at line 174).
  4. Matching rules are applied through `GtkStyleProvider` at the priority of each provider in `GtkStyleCascade` (see G45.1).
  5. Computed values are cached per node (`gtk/gtkcssnodestylecache.c`, not read in detail) unless `GTK_DEBUG=no-css-cache` is set (`gtk/gtkdebug.c:137`).
  6. Drawing uses the computed style through the GSK render node tree (outside scope).
- G44.2 Style cascade insertion: `gtk_style_context_add_provider_for_display` (`gtk/gtkstyleprovider.c:211-214`) adds a provider to the display's cascade at the given priority.
- G44.3 Built-in theme resource generation: `gtk/gtk.gresources.xml` is generated by `gen-gtk-gresources-xml.py` (`gtk/meson.build:739-756`). The Default SCSS is compiled at build time by sassc (preferred, flags `-a -M -t compact`) or grass (fallback, flags `--style expanded`) (`gtk/theme/Default/meson.build:16-33`). Output names: `Default-light.css`, `Default-dark.css`, `Default-hc.css`, `Default-hc-dark.css`.
- G44.4 Runtime wrapper: `gtk/theme/Default/gtk.css` (lines 1-15) contains four `@media` blocks combining `prefers-color-scheme` and `prefers-contrast`, each `@import url("resource:///org/gtk/libgtk/theme/Default/Default-VARIANT.css")`.
- G44.5 Built-in SCSS structure (`gtk/theme/Default/README`): `_colors.scss` (base colors; 103 lines), `_colors-public.scss` (119 lines; exports named colors via `@define-color`, e.g. `theme_fg_color` at line 10, `accent`-related and `wm_*` names up to line 105), `_drawing.scss` (508 lines; drawing mixins), `_common.scss` (4544 lines; all widget selectors). Entry files `Default-light.scss`, `Default-dark.scss`, `Default-hc.scss`, `Default-hc-dark.scss` set `$variant` and `$contrast` and `@import` the four partials (`gtk/theme/Default/Default-light.scss:1-13`).
- G44.6 Empty theme: `gtk/theme/Empty/gtk.css` (one file, no rules read).
- G44.7 Icons, cursors and fonts are not produced by the CSS path; they are read through GtkSettings properties (G42.19) and the icon theme code (out of scope).

## 5. Extension and integration points
- G45.1 Style providers implement the `GtkStyleProvider` interface. Standard priorities (`gtk/gtkstyleprovider.h`): FALLBACK = 1 (line 45), THEME = 200 (line 53), SETTINGS = 400 (line 64), APPLICATION = 600 (line 72), USER = 800 (line 83). Applications add providers with `gtk_style_context_add_provider_for_display` (`gtk/gtkstyleprovider.c:211`).
- G45.2 Custom themes are plain directories: `THEMENAME/gtk-4.N/gtk.css` or `gtk-VARIANT.css` (G42.1-G42.3), optionally with `gtk.gresource` (G42.5) and `settings.ini` (G42.9). Locations: `~/.local/share/themes`, `~/.themes` (deprecated), `$XDG_DATA_DIRS/themes`, or `$GTK_DATA_PREFIX/share/themes`.
- G45.3 Runtime-loaded CSS can contain `@import url("resource://...")` (used by the Default wrapper, G44.4) and the `gtk-4.N` fallback chain applies to theme directories only (G42.2).
- G45.4 Versioning and ABI: CSS theme directories are keyed by GTK major.minor (`gtk-4.N`); GTK 4 searches versions downward from its own minor version (G42.2), so themes built for older 4.x are picked up. The C API for providers is public (`gtk/gtkcssprovider.h`, `gtk/gtkstyleprovider.h`).
- G45.5 `GtkCssProvider:prefers-color-scheme`, `:prefers-contrast`, `:prefers-reduced-motion` are the hooks used by the media-query wrapper (G44.4); they are bound from GtkSettings (G42.7).
- G45.6 Inspector: the CSS editor and node tree live under `gtk/inspector/` (`css-editor.c`, `css-node-tree.c`, `inspector.css`), enabled by `GTK_DEBUG=interactive` (G42.18). Internals not read.

## 7. Facts of note
- G47.1 Deprecated (documented in code): `gtk_css_provider_load_named` (deprecated since 4.20, `gtk/gtkcssprovider.c:1952-1966`); `gtk-application-prefer-dark-theme` (`gtk/gtksettings.c:756` doc says deprecated since 4.20 and warns at runtime, `1343`); `lighter()`, `darker()`, `shade()`, `alpha()`, `mix()` CSS functions (each emits `gtk_css_parser_warn_deprecated`, `gtk/gtkcsscolorvalue.c:2108-2180`).
- G47.2 Deprecated load of custom CSS from `$HOME/.themes/` (debug message, `gtk/gtkcssprovider.c:1930`).
- G47.3 Default theme fallback: unknown theme names fall back to Default (`gtk/gtkcssprovider.c:2058-2059`). Theme name default is "Default" (`gtk/gtksettingsprivate.h:25`) while the Wayland portal fallback uses "Adwaita" (`gdk/wayland/gdksettings-wayland.c:270`). These two defaults are different and both exist in the code.
- G47.4 Deprecated-by-design HighContrast aliases: `HighContrast`, `HighContrastInverse`, `Adwaita-dark` (`gtk/gtkcssprovider.c:2045-2057`).
- G47.5 The provider's file path is recorded only for theme-directory loads (`_gtk_css_provider_get_theme_dir`, `gtk/gtkcssprovider.c:1845-1849`); `settings.ini` per-theme is read only when a theme directory is found (G42.9).
- G47.6 Setting `gtk-theme-name` via the GTK_THEME env var bypasses the property entirely (G42.8).
- G47.7 Named colors (`@name` references) are deprecated in the value parser: `gtk/gtkcsscolorvalue.c:1993-1995`. `@define-color` is deprecated at the same message (`gtk/gtkcsscolorvalue.c:1995` message text covers both).
- G47.8 Stated limitation in the gtk_css_provider_load_named doc: "The actual process of finding the theme might change between releases" (`gtk/gtkcssprovider.c:1960-1961`).
- G47.9 License: GNU Library General Public License v2 text in COPYING (`COPYING:1-2`). Source files carry their own headers (not re-checked).
