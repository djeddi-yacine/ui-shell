## 1. Purpose and shape
- KFI1.1 The project is "a set of plugins responsible for better integration of Qt applications when running on a KDE Plasma workspace" and "Applications do not need to link to this directly." Two components: KF6Style (KStyle) and FrameworkIntegrationPlugin (a KMessageBox addon). README: "### KF6Style" and "### FrameworkIntegrationPlugin" (`README.md:1-32`).
- KFI1.2 The README says KStyle makes a Qt style inherit "a consistent single-click or double-click activation setting, and the use of standard themed icons" (`README.md`, KF6Style section; also `src/kstyle/kstyle.qdoc:12-17`).
- KFI1.3 The plugin "currently provides an addon to KMessageBox which stores settings for asking users the same question again" (`README.md`, FrameworkIntegrationPlugin section). It also forwards KMessageBox notifications to KNotification (`src/integrationplugin/frameworkintegrationplugin.cpp:90-109`).
- KFI1.4 Top-level layout: `src/` (two subtrees for libraries plus `kpackage-install-handlers/`), `autotests/`, `tests/`, `LICENSES/`, `metainfo.yaml`, `KF6FrameworkIntegrationConfig.cmake.in`, `plasma_workspace.notifyrc` (the last three are top-level files listed by `ls`).
- KFI1.5 Metadata: `metainfo.yaml` sets `tier: 4`, `type: integration`, `group: Frameworks`, `subgroup: Tier 4`, `public_lib: true`, `release: true`, `deprecated: false`, platforms Linux, Windows, macOS, FreeBSD (`metainfo.yaml:1-16`).
- KFI1.6 Build system: CMake. `cmake_minimum_required(VERSION 3.30)` (`CMakeLists.txt:1`). The project is `FrameworkIntegration` with `VERSION ${KF_VERSION}` (`CMakeLists.txt:5`).
- KFI1.7 Version variables: `KF_VERSION` "6.33.0" (`CMakeLists.txt:3`), `KF_DEP_VERSION` "6.32.0" (`CMakeLists.txt:4`). The ECM minimum is 6.32.0 (`CMakeLists.txt:8`). The KF6Style library uses `SOVERSION 6` through the ECM generate-version call (`CMakeLists.txt:34-36`); the version header is `frameworkintegration_version.h` (`CMakeLists.txt:34`).
- KFI1.8 Minimum Qt: `REQUIRED_QT_VERSION 6.10.0` with `find_package(Qt6 ... CONFIG REQUIRED Gui Widgets)` (`CMakeLists.txt:29-30`). No Qt5 or KF5 path exists in this tree (`rg` for `KF5` and `Qt5` in `CMakeLists.txt` returned no match).
- KFI1.9 Minimum KF: `KF_DEP_VERSION` 6.32.0 for every required KF6 package (`CMakeLists.txt:38-42`). The KCMUtils and Qt Quick dependencies of Darkly and Breeze are not part of this tree.
- KFI1.10 Libraries and targets: `KF6Style` (`add_library(KF6Style kstyle.cpp)`, alias `KF6::Style`, `EXPORT_NAME Style`) (`src/kstyle/CMakeLists.txt:4-10`); `FrameworkIntegrationPlugin` as a MODULE (`src/integrationplugin/CMakeLists.txt:1-2`).
- KFI1.11 Plugin install directory: `${KDE_INSTALL_PLUGINDIR}/kf6` (`src/integrationplugin/CMakeLists.txt:13`).
- KFI1.12 Style export macro: `ecm_generate_export_header(KF6Style BASE_NAME KStyle GROUP_BASE_NAME KF ...)` produces `kstyle_export.h` (`src/kstyle/CMakeLists.txt:13`); the header includes `<kstyle_export.h>` and declares `class KSTYLE_EXPORT KStyle` (`src/kstyle/kstyle.h:33`, `:52`).
- KFI1.13 The style library is built from one source file, `kstyle.cpp`, and its public headers are installed to `${KDE_INSTALL_INCLUDEDIR_KF}/KStyle` (`src/kstyle/CMakeLists.txt:4`, `:51-54`).

## 2. Theme input (how configuration reaches it)
- KFI2.1 No environment variable is read in `src/`. A search for `getenv`, `qgetenv` and `qEnvironmentVariable` returned no matches.
- KFI2.2 The KStyle config reads use the shared config object `KSharedConfig::openConfig()` with no file name (`src/kstyle/kstyle.cpp:222`, `:374`, `:382`, `:390`, `:425`). The file name behind the no-argument call is not in this tree (UNVERIFIED here: it is `kdeglobals` by KDE convention; the autotest sets up `kdeglobals` at `autotests/kstyle_unittest.cpp:31`).
- KFI2.3 Group `KDE`, key `ShowIconsOnPushButtons`, default true, feeds `SH_DialogButtonBox_ButtonsHaveIcons` (`src/kstyle/kstyle.cpp:374-375`).
- KFI2.4 Group `KDE-Global GUI Settings`, key `GraphicEffectsLevel`, default true, feeds `SH_Widget_Animate` (`src/kstyle/kstyle.cpp:382-383`).
- KFI2.5 Group `Toolbar style`, keys `ToolButtonStyle` (default `TextBesideIcon`) and `ToolButtonStyleOtherToolbars` (default `NoText`), feed `SH_ToolButtonStyle`. The second key is used when the parent widget is a QToolBar with a property named `otherToolbar` (`src/kstyle/kstyle.cpp:390-407`).
- KFI2.6 Group `KDE`, key `ScrollbarLeftClickNavigatesByPage`, default false, is inverted into `SH_ScrollBar_LeftClickAbsolutePosition` (`src/kstyle/kstyle.cpp:425-426`).
- KFI2.7 Key `KDE_COLOR_SCHEME_PATH` is not read by this tree. The colour scheme is consumed through `KColorScheme` (Section 3).
- KFI2.8 Plugin config: `KMessageBoxDontAskAgainConfigStorage` reads and writes group `Notification Messages` (`src/integrationplugin/frameworkintegrationplugin.cpp:17`, `:32`, `:42`, `:53`, `:65`, `:84`). The file is `KMessageBox_againConfig` if set through `setConfig`, otherwise `KSharedConfig::openConfig()` (`frameworkintegrationplugin.cpp:17`, `frameworkintegrationplugin.h:34-37`).
- KFI2.9 Stored values for "don't ask again": `yes`/`true` maps to `KMessageBox::PrimaryAction`, `no`/`false` maps to `KMessageBox::SecondaryAction`, both return "do not show" (`frameworkintegrationplugin.cpp:18-26`). Any other value means show the dialog (`:27`). Writes use `KConfig::Persistent`, plus `KConfigGroup::Global` when the key name starts with `:` (`:38-41`, `:49-52`).
- KFI2.10 `enableAllMessages` deletes every entry of the group `Notification Messages` (`frameworkintegrationplugin.cpp:58-75`). `enableMessage` deletes one entry and calls `sync()` (`:77-88`).
- KFI2.11 Notification event names: `messageWarning` (QMessageBox::Warning), `messageCritical` (Critical), `messageQuestion` (Question), `messageInformation` (default) (`src/integrationplugin/frameworkintegrationplugin.cpp:93-106`). Sent with `KNotification::event(messageType, message, QPixmap(), KNotification::DefaultEvent | KNotification::CloseOnTimeout)` (`:108`). The parent widget argument is unused (`:90`).
- KFI2.12 The plugin's `reparseConfiguration` slot calls `KSharedConfig::openConfig()->reparseConfiguration()` (`src/integrationplugin/frameworkintegrationplugin.cpp:118-121`; slot declared at `frameworkintegrationplugin.h:56-57`).
- KFI2.13 Plugin loading: the plugin object exposes the Qt plugin IID `org.kde.FrameworkIntegrationPlugin` through `Q_PLUGIN_METADATA` (`src/integrationplugin/frameworkintegrationplugin.h:51`). Its constructor publishes two interfaces as QObject properties, `KMESSAGEBOXDONTASKAGAIN_PROPERTY` and `KMESSAGEBOXNOTIFY_PROPERTY` (`src/integrationplugin/frameworkintegrationplugin.cpp:111-116`). The loader that reads these properties is in KF6 WidgetsAddons, not in this tree.

## 3. Color and style model
- KFI3.1 No colour formula, shade, mix, contrast or HCY/HSL conversion is defined in this tree. A search of `src/` for `KColorUtils`, `mix`, `shade`, `contrast`, `setAlpha` gave no style formula: the colour work is delegated to KF6 ColorScheme (`src/kstyle/CMakeLists.txt:35` links `KF6::ColorScheme`; `CMakeLists.txt:39`).
- KFI3.2 `KStyle::standardPalette()` returns `KColorScheme::createApplicationPalette(KSharedConfig::openConfig())` (`src/kstyle/kstyle.cpp:220-223`). This is the only palette source KStyle provides. The config object is the no-argument `KSharedConfig` (see KFI2.2).
- KFI3.3 Palette override of KMessageWidget in `polish()`: the widget's `QPalette::Window` role is set from a `KColorScheme` foreground role (`src/kstyle/kstyle.cpp:196-215`):
  - `KMessageWidget::Positive` uses `KColorScheme::PositiveText` (`:201-202`);
  - `KMessageWidget::Information` uses `KColorScheme::ActiveText` (`:204-205`);
  - `KMessageWidget::Warning` uses `KColorScheme::NeutralText` (`:207-208`);
  - `KMessageWidget::Error` uses `KColorScheme::NegativeText` (`:210-211`).
  The colour is the foreground colour of the role (`.color()`), applied with `palette.setColor(QPalette::Window, color)` and `messageWidget->setPalette(palette)` (`:197-198`, `:199`, `:214-215`). The result is not passed through any mix or contrast step.
- KFI3.4 Style palette roles are not defined in this tree. The `KStatefulBrush`/`KColorScheme` brushes used by Darkly and Breeze are in their own trees (see KFI5.6).
- KFI3.5 Icon colour: none defined here. Icons come from `QIcon::fromTheme` with freedesktop names (Section 3.6 below).

## 4. Architecture (classes, plugin points, entry points)
- KFI4.1 `class KSTYLE_EXPORT KStyle : public QCommonStyle` with `Q_OBJECT` (`src/kstyle/kstyle.h:52-54`). Constructor and destructor (`:57-58`). The private implementation is `KStylePrivate *const d` (`:158`).

Initial values: `controlCounter` and `subElementCounter` are `X_KdeBase` (0xff000000), `hintCounter` is `X_KdeBase + 1` (`:60-64`). The reserved hint `SH_KCustomStyleElement` is `0xff000001` (`:48`).

  Everything else falls through to `QCommonStyle` (`kstyle.cpp:217`, `:366`, `:433`, `:456`).
- KFI4.4 Hints implemented in `styleHint()`, in source order: `SH_DialogButtonBox_ButtonsHaveIcons` (`kstyle.cpp:372-376`); `SH_ItemView_ArrowKeysNavigateIntoChildren` returns true (`:378-379`); `SH_Widget_Animate` (`:381-384`); `QStyle::SH_Menu_SubMenuSloppyCloseTimeout` returns 300 ms (`:386-387`); `SH_ToolButtonStyle` (`:389-415`); `SH_KCustomStyleElement` (`:417-422`); `SH_ScrollBar_LeftClickAbsolutePosition` (`:424-427`).
- KFI4.5 `SH_ToolButtonStyle` mapping (`src/kstyle/kstyle.cpp:409-414`): `textbesideicon` and `icontextright` map to `Qt::ToolButtonTextBesideIcon`; `textundericon` and `icontextbottom` map to `Qt::ToolButtonTextUnderIcon`; `textonly` maps to `Qt::ToolButtonTextOnly`; any other value (including `iconOnly`) maps to `Qt::ToolButtonIconOnly`. The comparison is on the lower-cased string (`:404`, `:406`).
- KFI4.6 `polish()` side effects (`src/kstyle/kstyle.cpp:181-218`): sets `Qt::WA_Hover` on item-view viewports (`:183-186`); for QDialogButtonBox it adds a `Ctrl+Return` shortcut that clicks the OK button (`:188-195`); for KMessageWidget it sets the Window palette role by message type (KFI3.3, `:196-215`).
- KFI4.7 Custom element registry (the helper API that Breeze and Darkly use):
  - Static API on KStyle: `customStyleHint(const QString&, const QWidget*)`, `customControlElement(...)`, `customSubElement(...)` (`src/kstyle/kstyle.h:91`, `:96`, `:101`). They call the static helper `customStyleElement()` (`src/kstyle/kstyle.cpp:71-82`, `:84-97`).
  - The helper checks the widget's style for the class-info key `X-KDE-CustomElements` (`src/kstyle/kstyle.cpp:73`). If absent it returns 0. Otherwise it saves the widget's `objectName`, sets it to the element name, calls `styleHint(SH_KCustomStyleElement, nullptr, widget)` and restores the name (`:77-81`).
  - Protected API for the style: `newStyleHint(const QString&)`, `newControlElement(const QString&)`, `newSubElement(const QString&)` (`src/kstyle/kstyle.h:134`, `:139`, `:144`). They pass the name to `newStyleElement()` (`src/kstyle/kstyle.cpp:152-164`, `:166-179`). The element name must contain `SH_`, `CE_` or `SE_`; otherwise the id is 0 (`:154-156`). Ids are assigned from the counters in KFI4.2 and cached in `styleElements` (`:157-163`).
  - Resolution inside the style: `styleHint(SH_KCustomStyleElement)` returns `d->styleElements.value(widget->objectName(), 0)` (`src/kstyle/kstyle.cpp:417-422`).
  - The source documents the design as a "Custom Style Element runtime extension" (`src/kstyle/kstyle.cpp:109-142`). A style must add `Q_CLASSINFO("X-KDE-CustomElements", "true")` for the lookup to work (`kstyle.h:103-120` and `kstyle.cpp:127-129`).
- KFI4.8 Plugin classes (`src/integrationplugin/frameworkintegrationplugin.h`):
  - `KMessageBoxDontAskAgainConfigStorage : public KMessageBoxDontAskAgainInterface` (`:17`), with a private `KConfig *KMessageBox_againConfig` (`:40`) set through `setConfig()` (`:34-37`). Its methods: `shouldBeShownTwoActions`, `shouldBeShownContinue`, `saveDontShowAgainTwoActions`, `saveDontShowAgainContinue`, `enableAllMessages`, `enableMessage` (`:28-33`).
  - `KMessageBoxNotify : public KMessageBoxNotifyInterface` (`:43`), method `sendNotification(QMessageBox::Icon, const QString&, QWidget*)` (`:46`).
  - `KFrameworkIntegrationPlugin : public QObject` (`:49`), with `Q_PLUGIN_METADATA(IID "org.kde.FrameworkIntegrationPlugin")` (`:51`), slot `reparseConfiguration()` (`:56-57`), members `m_dontAskAgainConfigStorage` and `m_notify` (`:60-61`).
- KFI4.9 Platform theme: no `QPlatformTheme`, font, icon-theme or palette plugin is in this tree (grep for `QPlatformTheme`, `QStyleFactory`, `setPalette` in the tree returned only the `KStyle`/`KMessageWidget` matches listed above).
