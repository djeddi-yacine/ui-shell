## 2. Theme input (how configuration reaches it)
- KD22.1 [kdecoration] The decoration library reads no configuration file and no environment variable. Settings arrive through a `DecorationBridge` object (`src/decorationsettings.h:93` constructor `DecorationSettings(DecorationBridge *bridge, ...)`; `src/decorationsettings.cpp:14-15` calls `bridge->settings(this)`).
- KD22.2 [kdecoration] Decoration construction arguments are a `QVariantList`. `Decoration::Private` finds the bridge by scanning maps for key `bridge` (`src/decoration.cpp:23-30`, `Q_UNREACHABLE()` if absent) and reads key `style` as `Style` (`src/decoration.cpp:190-195`). - KD22.3 [kdecoration] Bridge contract: `DecorationBridge` (private export) has pure virtual `createClient(DecoratedWindow*, Decoration*)` and `settings(DecorationSettings*)` (`src/private/decorationbridge.h:41-42`); the compositor implements it (not in this repo).
- KD22.4 [kdecoration] Font-derived sizes: `gridUnit` is the height of the bounding rect of `M` in the settings font, rounded up to an even number; `smallSpacing = max(2, gridUnit / 4)` (integer division); `largeSpacing = gridUnit` (`src/decorationsettings.cpp:19-30`). Recomputed on `fontChanged` (`:37`).
- KD22.5 [kdecoration] Button layout comes from settings lists `decorationButtonsLeft` and `decorationButtonsRight` (`src/decorationsettings.h:59`, `:63`) and border size from `borderSize` (`:67`, enum `BorderSize`).
- KD22.6 [kiconthemes] Theme name lookup `KIconTheme::current()`, first match wins: forced override `_themeOverride` (`src/kicontheme.cpp:683`), cached `_theme` (`:681-686`), application config `Icons/Theme` opened with `KConfig::NoGlobals` (`:693-696`), `QIcon::themeName()` unless empty or `hicolor`, then kdeglobals `Icons/Theme` with fallback `breeze` (`:702`), finally `defaultThemeName()` which returns `hicolor` (`:772-775`). - KD22.7 [kiconthemes] With BreezeIcons compiled in, `initThemeHelper` (`src/kicontheme.cpp:68-111`) calls `BreezeIcons::initIcons()` (`:85`), reads `Icons/Theme` from `KSharedConfig::openConfig()` with fallback `breeze` (`:105`), and calls `QIcon::setThemeName("KIconEngine")` (`:110`). - KD22.8 [kiconthemes] `KIconTheme::initTheme()` adds `<libpath>/kiconthemes6` to Qt library paths for every existing library path so the engine plugin is found first (`src/kicontheme.cpp:123-143`; startup via `Q_COREAPP_STARTUP_FUNCTION`, `:144`).

- KD22.10 [kiconthemes] Theme roots: for each of `GenericDataLocation` + `icons` and `pixmaps`, plus `:/icons` (embedded resources), the theme directory is `<root>/<name>/` (`src/kicontheme.cpp:384-387`, `:391-392`). - KD22.11 [kiconthemes] Theme description file: `index.theme` with main section `[Icon Theme]`, or `theme.desktop` with `[KDE Icon Theme]`; `index.theme` is preferred within a root (`src/kicontheme.cpp:395-415`). The first root that contains either file becomes the theme directory (`:405-416`).

- KD23.20 [kiconthemes] Selected accent tint: `tintRatio = 0.85`; per channel in float RGB, `c = accent_c * 0.85 + highlightedText_c * (1.0 - 0.85)` for r, g, b; alpha is kept from accent (`src/kiconcolors.cpp:115-119`). The colour is written with `QColor::name()` (`:130`).
- KD23.21 [kiconthemes] Qt mode to KIconLoader state (`src/kiconengine.cpp:59-73`): `Normal` to `DefaultState`, `Active` to `ActiveState`, `Disabled` to `DisabledState`, `Selected` to `SelectedState`, anything else to `DefaultState`.
- KD23.22 [kiconthemes] Symbolic recolour gate: an SVG or SVGZ file is rewritten only when the theme has `FollowsColorScheme=true` (`src/kiconloader.cpp:721-723`). Non-SVG files (PNG, XPM) are loaded unchanged (`:725-727`).
- KD23.23 [kiconthemes] SVG rewrite: streams the file with `QXmlStreamReader`; the first `<style id="current-color-scheme">` element has its text replaced by the stylesheet from KD23.18/19, its content tokens are skipped, and all other tokens are copied except whitespace and comments (`src/kiconloader.cpp:670-713`; match `:697`, replacement `:700`, flag `:705`). The rewrite is text substitution; no colour maths runs on SVG content.
- KD23.24 [kiconthemes] Cache key: `paletteId` packs `text`, `highlight`, `highlightedText`, `background` as 8 hex digits each (`uintToHex(rgba)`, `src/kiconloader.cpp:118-127`). Key suffix `_selected` is added when the theme follows the colour scheme and the state is SelectedState (`:666`). `accent`, `positiveText`, `neutralText` and `negativeText` are not part of the key (`:118-127`, observed).
- KD23.25 [kiconthemes] Post-load state effects on raster output (`src/kiconloader.cpp:1177-1184`): when the group is Desktop or Panel and state is ActiveState, `KIconEffect::toActive`; when state is DisabledState and the group is a valid group, `KIconEffect::toDisabled`.
- KD23.26 [kiconthemes] `toActive(img)` = `toGamma(img, 0.7)` (`src/kiconeffect.cpp:714-717`).
- KD23.27 [kiconthemes] `toDisabled(img)` = `toGray(img, 1)` (`src/kiconeffect.cpp:701-705`).
- KD23.28 [kiconthemes] `toGamma(img, value)`: `gamma = 1 / (2 * value + 0.5)`; each colour channel `c' = (unsigned char)(pow(c / 255.0f, gamma) * 255)`; alpha unchanged (`src/kiconeffect.cpp:435-449`). With value 0.7 the exponent is 1 / 1.9 (about 0.5263).
- KD23.29 [kiconthemes] `toGray(img, value)`: returns unchanged for value 0. For value 1.0, each pixel becomes `g = qGray(rgb)` on all three channels and keeps alpha (`src/kiconeffect.cpp:273-290`, `value == 1.0` branch `:281-287`). For 0 < value < 1: `val = (unsigned char)(255.0 * value)`; each channel becomes `(val * g + (0xFF - val) * channel) >> 8` (`:292-300`).
- KD23.30 [kiconthemes] `qGray` is not defined in refs/kiconthemes; its formula is Qt's, not read from refs. Verify against Qt source before reimplementing (see KD26.6).
- KD23.31 [kiconthemes] Engine-level colour choice: `KIconEngine` uses the colours it was built with when set; otherwise the loader's colours (`src/kiconengine.cpp:91-126`, `d->mCustomColors ? std::make_optional(d->mColors) : std::nullopt`).
