# oxygen: KDE Plasma Oxygen style (Qt widget style plus KDE settings), Qt5 and Qt6 builds from one tree

Source: refs/oxygen (shallow clone; commit f55ce3d, 2026-11-13; branch master). License: per-file SPDX; `kstyle/oxygenstyleplugin.cpp:2-3` says GPL-2.0-or-later; the `LICENSES/` directory holds the texts (GPL-2.0-only, GPL-2.0-or-later, GPL-3.0, LGPL-2.x, CC0-1.0, LicenseRef-KDE-Accepted-GPL). Scope: `CMakeLists.txt`, `kstyle/` (style, plugin, config schema, helper, animations engine headers), `liboxygen/` (shared color helper, animation base), `color-schemes/`, `kstyle/oxygen.themerc` (head only). Window decorations (`kdecoration/`), icon and cursor assets, wallpapers, `lookandfeel/` and the KCM UI were not studied.
Id prefix: OX.

## 1. Purpose and shape
- OX1.1 Oxygen is a classic KDE Plasma application style (`README.md:3`). The style is a C++ Qt widget style built as a plugin module (`kstyle/CMakeLists.txt:67`, `add_library(oxygen${QT_MAJOR_VERSION} MODULE ...)`). The style class `Oxygen::Style` derives from KDE's `KStyle` (`kstyle/oxygenstyle.h:79`, include at `kstyle/oxygenstyle.h:42`). `KStyle` lives in the KDE Frameworks Style module, not in this repo (UNVERIFIED: its base QStyle class chain not read).
- OX1.2 Toolkit targets: the CMake project builds two variants from the same sources. Qt5 is built as `liboxygen5`/`kstyle5` with `KF5` (`CMakeLists.txt:65-91`); Qt6 as `liboxygen6`/`kstyle6` with `KF6` (`CMakeLists.txt:95-129`). `BUILD_QT5` and `BUILD_QT6` options default to ON (`CMakeLists.txt:36-37`), and CI can force one (`CMakeLists.txt:39-45`).
- OX1.3 Minimum versions: Qt5 `5.15.2` (`CMakeLists.txt:12`), KF5 `5.102.0` (`CMakeLists.txt:13`), Qt6 `6.11.0` (`CMakeLists.txt:14`), KF6 `6.30.0` (`CMakeLists.txt:15`). The Qt6 build also needs `Qt6GuiPrivate` (`CMakeLists.txt:104`). Version branches in code use `QT_VERSION >= QT_VERSION_CHECK(6,0,0)` at `kstyle/oxygenstyle.cpp:1431`, `:4350`, `:4741`, and `KGUIADDONS_VERSION < QT_VERSION_CHECK(6, 4, 0)` at `kstyle/oxygenstyle.cpp:421`.
- OX1.4 Language C++ with Qt moc, `kconfig_add_kcfg_files` code generation (KConfig XT). Build system CMake with ECM (`CMakeLists.txt:30`).
- OX1.5 Layout that matters:
  - `kstyle/`: style core (`oxygenstyle.cpp` 8479 lines, `oxygenstyle.h`), plugin factory (`oxygenstyleplugin.cpp/.h`, `oxygen.json`), config schema (`oxygen.kcfg`, `oxygenstyleconfigdata.kcfgc`), color/shade helper (`oxygenstylehelper.cpp/.h`), shadows (`oxygenshadowhelper.*`, `oxygenframeshadow.*`, `oxygenmdiwindowshadow.*`), blur (`oxygenblurhelper.*`), window drag (`oxygenwindowmanager.*`), splitter proxy (`oxygensplitterproxy.*`), mnemonics (`oxygenmnemonics.*`), `oxygen.themerc` (desktop theme metadata, 141 lines).
  - `kstyle/animations/`: per-widget animation engines (`oxygenanimations.*`, `oxygenbaseengine.*`, `oxygen*engine.*`, `oxygen*data.*`).
  - `kstyle/transitions/`: widget transition engines (combobox, label, line edit, stacked widget).
  - `kstyle/config/`: KCM settings module (`oxygenstyleconfig.cpp`, `oxygenstyleconfigmodule.cpp`, `oxygenanimationconfigwidget.cpp`, `oxygenstyleconfig.json`, `ui/`).
  - `kstyle/demo/`: style simulator app (`main.cpp`, `oxygensimulator.cpp`).
  - `liboxygen/`: shared library linked by both style and config: `oxygenhelper.cpp/.h` (`Helper`, color math), `oxygenanimation.h` (QPropertyAnimation wrapper), `oxygenshadowcache.cpp`, `oxygenitemmodel.*`, shadow config kcfg files (`oxygenactiveshadowconfigdata.kcfg`, `oxygeninactiveshadowconfigdata.kcfg`).
  - `color-schemes/`: `Oxygen.colors`, `OxygenCold.colors`, `OxygenDark.colors` (KDE color scheme files, 6 entries in the directory listing including `CMakeLists.txt` and `extra/`).
  - `kdecoration/`, `lookandfeel/`, `desktoptheme/`, `cursors/`, `wallpapers/`: not studied (other Plasma components per `README.md:10-17`).
- OX1.6 Build dependencies (declared in `CMakeLists.txt`): KF6 components `I18n, Config, CoreAddons, GuiAddons, KCMUtils, WidgetsAddons, Service, Completion, FrameworkIntegration, WindowSystem` (`CMakeLists.txt:106-116`); KF5 equivalents in `CMakeLists.txt:74-84` (not read in detail). The style links `Qt::Core Qt::Gui Qt::Widgets Qt::DBus Qt::Quick`-class targets and `KF::GuiAddons KF::Style KF::WindowSystem` (`kstyle/CMakeLists.txt:69-71`), and `XCB::XCB` when X11 is enabled (`kstyle/CMakeLists.txt:74`).

## 3. Color and style model
- OX3.1 Color helper class: `Oxygen::Helper` (`liboxygen/oxygenhelper.h:222`), constructed from a `KSharedConfig::Ptr` (`liboxygen/oxygenhelper.cpp:37-41`). Subclass `StyleHelper` adds style-specific caches (`kstyle/oxygenstylehelper.h:26`, constructor `kstyle/oxygenstylehelper.cpp:32-36`). `Style` owns it (`kstyle/oxygenstyle.cpp:188`).
- OX3.2 Derived values stored in the helper: `_contrast` from `KColorScheme::contrastF`, `_bgcontrast = min(1.0, 0.9 * _contrast / 0.7)` (`liboxygen/oxygenhelper.cpp:52-54`; same formula in `Helper::init` at `liboxygen/oxygenhelper.cpp:858-866`; the comment there says the background contrast is 0.9 when the KDE contrast is 0.7). Stateful brushes `_viewFocusBrush`, `_viewHoverBrush`, `_viewNegativeTextBrush` (`liboxygen/oxygenhelper.cpp:56-58`; members `liboxygen/oxygenhelper.h:492-494`).
- OX3.3 Shade functions. All shades are delegated to KDE's `KColorScheme::shade(color, role, amount)` and `KColorUtils::shade/mix/luma` (`liboxygen/oxygenhelper.cpp:13-14` includes). The shade roles used are `LightShade`, `MidlightShade`, `MidShade` (`liboxygen/oxygenhelper.cpp:192`, `:207`, `:233`, `:237`, `:254`, `:275`, `:297`, `:312`, `:327`). The internal formulas:
  - `calcLightColor(c)`: unchanged if `highThreshold(c)`, else `KColorScheme::shade(c, LightShade, _contrast)` (`liboxygen/oxygenhelper.cpp:290-302`).
  - `calcDarkColor(c)`: if `lowThreshold(c)` then `KColorUtils::mix(calcLightColor(c), c, 0.3 + 0.7 * _contrast)`, else `KColorScheme::shade(c, MidShade, _contrast)` (`liboxygen/oxygenhelper.cpp:304-316`, lines 311-312 for the branch).
  - `calcShadowColor(c)`: mixes black into the color with alpha, then shades (`liboxygen/oxygenhelper.cpp:319-330`, mix at `:326`).
  - `backgroundRadialColor`, `backgroundTopColor`, `backgroundBottomColor`: shade with `_bgcontrast` or `KColorUtils::shade(color, (my - by) * _bgcontrast)` where `my` and `by` are luma values (`liboxygen/oxygenhelper.cpp:224-285`; key lines `:233`, `:237`, `:254-258`, `:275-281`).
  - `backgroundColor(color, ratio)`: `KColorUtils::mix(backgroundTopColor(color), color, a)` or `mix(color, backgroundBottomColor(color), a)` (`liboxygen/oxygenhelper.cpp:339-355`).
  - `decoColor(bg, color)`: `KColorUtils::mix(background, color, 0.8 * (1.0 + _contrast))` (`liboxygen/oxygenhelper.cpp:425-432`).
  - `alphaColor(color, alpha)`: `setAlphaF(alpha * color.alphaF())` (`liboxygen/oxygenhelper.cpp:215-221`).
- OX3.4 Threshold classification: `lowThreshold(c)` is true when the color darkened by `KColorScheme::shade(c, MidShade, 0.5)` has higher luma than `c` (`liboxygen/oxygenhelper.cpp:185-196`); `highThreshold(c)` mirrors it with `LightShade` and a lower luma (`liboxygen/oxygenhelper.cpp:200-211`, lines `:207-208`). Results cached per `colorKey(color)`.
- OX3.5 Caching: `Helper` keeps `_lightColorCache`, `_lowThreshold`, `_backgroundCache` (`setMaxCost(64)` at `liboxygen/oxygenhelper.cpp:866`), keyed by a packed color (`colorKey`). Cache size is set from the `MaxCacheSize` config key (`kstyle/oxygenstyle.cpp:1771`).
- OX3.6 Whether any Oxygen draw code calls Qt's own `QColor::lighter()` / `darker()` (HSV value scaling, `src/gui/painting/qcolor.cpp` in the qt4 repo) rather than KDE's shade functions was not traced. UNVERIFIED.
- OX3.7 Color-scheme (light/dark): handled by KDE's `KColorScheme` through the palette the application receives; the style does not contain a light/dark switch of its own. The `color-schemes/OxygenDark.colors` and `OxygenCold.colors` files are separate KDE schemes (`color-schemes/`). UNVERIFIED: how the KDE palette is applied to Qt apps is outside this repo.
- OX3.8 Per-state handling: animations interpolate between states. Hover, pressed, focus, enabled, and the "disabled palette" use `_helper->disabledPalette(palette, opacity)` during enable/disable transitions (`kstyle/oxygenstyle.cpp:1232-1240`). Hover/focus brushes come from the `KStatefulBrush` members in OX3.2.
- OX3.9 Metrics: `Style::pixelMetric()` at `kstyle/oxygenstyle.cpp:520`; values use config keys such as `ScrollBarWidth` (UNVERIFIED: which metrics read which keys, not traced).

## 4. Output and rendering path
- OX4.1 Entry: `Oxygen::StylePlugin` derives from `QStylePlugin` (`kstyle/oxygenstyleplugin.h:12`), with `Q_PLUGIN_METADATA(IID "org.qt-project.Qt.QStyleFactoryInterface" FILE "oxygen.json")` (`kstyle/oxygenstyleplugin.h:16`). `oxygen.json` contains `{ "Keys": [ "Oxygen" ] }` (`kstyle/oxygen.json:1`). `StylePlugin::keys()` returns `"Oxygen"` (`kstyle/oxygenstyleplugin.cpp:23-25`); `create(key)` returns `new Style` when `key.toLower() == "oxygen"` (`kstyle/oxygenstyleplugin.cpp:11-17`).
- OX4.2 Call chain on a widget (in order):
  1. Qt calls `Style::polish(QWidget*)` (`kstyle/oxygenstyle.cpp:228`). It calls `_animations->registerWidget`, `_transitions->registerWidget`, `_windowManager->registerWidget` (`kstyle/oxygenstyle.cpp:234-236`), then the KStyle base polish (`:430`).
  2. Paint: `Style::drawPrimitive` (`kstyle/oxygenstyle.cpp:946`), `Style::drawControl` (`:1060`), `Style::drawComplexControl` (`:1169`) take the element and draw with `QPainter` using colors from `_helper` (`StyleHelper`) and the palette.
  3. Animated state: animation engines (`kstyle/animations/oxygenanimations.cpp:62` `setupEngines`) hold per-widget data (`*Data` classes) and drive opacity or phase; the style reads it in draw code (e.g. `kstyle/oxygenstyle.cpp:1232-1240`).
  4. Frame, shadow and blur: `ShadowHelper` (`kstyle/oxygenshadowhelper.h`), `BlurHelper` (`kstyle/oxygenblurhelper.h`), `FrameShadow` and `MdiWindowShadow` (`kstyle/oxygenframeshadow.*`, `kstyle/oxygenmdiwindowshadow.*`) are created in the Style constructor (`kstyle/oxygenstyle.cpp:187-192`).
- OX4.3 Rendering primitives: the draw entry points are QPainter-based inside `Style` (OX4.2). UNVERIFIED for individual elements. `kstyle/oxygentileset.h` is included by `kstyle/oxygenstyle.h:40`; its use was not traced. `oxygen.themerc` holds metadata only as far as read (OX2.8).
- OX4.4 Animations: `liboxygen/oxygenanimation.h:23` defines `Animation : QPropertyAnimation` with duration set in the constructor (`:33-35`). Engines are `BaseEngine : QObject` (`kstyle/animations/oxygenbaseengine.h:23`). The step count is `AnimationData::setSteps(StyleConfigData::animationSteps())` (`kstyle/animations/oxygenanimations.cpp:65`). Enable flags and durations come from the config groups in OX2.2.
- OX4.5 Transitions: `kstyle/transitions/` engines (`oxygencomboboxengine.cpp`, `oxygenlabelengine.cpp`, `oxygenlineeditengine.cpp`, `oxygenstackedwidgetengine.cpp`) with `oxygentransitionwidget.cpp` as the overlay.
- OX4.6 Window decoration: `kdecoration/` holds the window-decoration plugin (not studied). The style's `WindowManager` handles window drag and move (`kstyle/oxygenwindowmanager.*`), with `WindowDragEnabled`, `WindowDragMode`, `UseWMMoveResize`, and the white/black lists (OX2.2).

## 5. Extension and integration points
- OX5.1 Plugin: the style is a Qt style plugin (`QStylePlugin`) with IID `org.qt-project.Qt.QStyleFactoryInterface` (`kstyle/oxygenstyleplugin.h:16`). Qt finds it by key "Oxygen" through the `/styles` plugin directory (Qt's own factory; see the `qt4` study for the Qt4 side of that mechanism).
- OX5.2 Build artefact names: `oxygen5` and `oxygen6` modules (`kstyle/CMakeLists.txt:67`), built with `MODULE` linkage, so the artefacts are Qt plugins (`.so`), not shared libraries linked by applications. Helper library names: `liboxygen5`, `liboxygen6`, `oxygenstyle5/6` (`CMakeLists.txt:90-91`, `:128-129`, `kstyle/CMakeLists.txt:70`).
- OX5.3 Shared helper library: `liboxygen` is used by both the style and the KCM (`liboxygen/CMakeLists.txt`, `kstyle/config/CMakeLists.txt`). Exported with `OXYGEN_EXPORT` (`liboxygen/oxygenhelper.h:222`, `liboxygen/oxygenanimation.h:23`).
- OX5.4 Config module: KCM in `kstyle/config/` (`oxygenstyleconfigmodule.*`) with its own `oxygenstyleconfig.json` plugin metadata (not read in detail). `kstyle/config/main.cpp` is the KCM entry (not read).
- OX5.5 ABI and version coupling: Qt5 and Qt6 built separately; Qt6 uses `Qt6GuiPrivate` (`CMakeLists.txt:104`, `kstyle/CMakeLists.txt` link on X11 at `:~73-74`). The Qt5 build needs `Qt5X11Extras` (`CMakeLists.txt:86`). Code guards on `KGUIADDONS_VERSION < 6.4.0` (`kstyle/oxygenstyle.cpp:421`).
- OX5.6 KDE coupling: `KStyle` base, `KColorScheme`, `KColorUtils`, `KStatefulBrush`, `KSharedConfig`, KConfig XT (`kconfig_add_kcfg_files`, `kstyle/CMakeLists.txt:66`). The style advertises `X-KDE-CustomElements` (`kstyle/oxygenstyle.h:84`).

## 7. Facts of note
- OX7.1 Version split: the same source tree builds Qt5/KF5 and Qt6/KF6 variants (OX1.2). Minimum Qt6 is 6.11.0 (`CMakeLists.txt:14`), so the Qt5 path is maintained on master alongside Qt6.
- OX7.2 The style does not read a Qt-side settings file of its own for colors: colors come from KDE's color scheme through `KColorScheme`/`KStatefulBrush` (OX2.3).
- OX7.3 Shade math is KDE's (`KColorScheme::shade`, `KColorUtils`), so the exact formula is in KF, not here (UNVERIFIED).
- OX7.4 Contrast is a global KDE setting, and background contrast is derived as `min(1.0, 0.9 * contrast / 0.7)` (OX3.2).
- OX7.5 Animations are optional and configurable per widget class (OX2.2, OX4.4).
- OX7.6 Qt6 build needs private Qt headers (`Qt6GuiPrivate`, OX5.5).
- OX7.7 Config changes are applied live through `configurationChanged()` (OX2.5).
