## 1. Purpose and shape
- QB1.1 Qt 6 C++ application framework. This repo is the source of the QPA platform-theme interface (QPlatformTheme), the style base classes (QStyle, QCommonStyle, QFusionStyle, QStyleSheetStyle) and the palette class (QPalette). Targets Qt 6 (ids of the plugin interface are version 5.1). `src/gui/kernel/qplatformtheme.h:43`, `src/gui/kernel/qplatformthemeplugin.h:25`.
- QB1.2 Layout that matters for theming:
  - `src/gui/kernel/`: QPlatformTheme (qplatformtheme.*), theme plugin base and factory (qplatformthemeplugin.*, qplatformthemefactory*), QPalette (qpalette.*), QGuiApplication (qguiapplication.cpp).
  - `src/widgets/kernel/qapplication.cpp`: widget-side palette/font initialisation and style override handling.
  - `src/widgets/styles/`: QStyle base, QCommonStyle, QFusionStyle, QStyleSheetStyle, QStyleFactory, QStylePlugin.
  - `src/plugins/platformthemes/gtk3/`: plugin "gtk3" (reads GTK 3 settings, colors, fonts).
  - `src/plugins/platformthemes/xdgdesktopportal/`: plugin "xdgdesktopportal" (reads org.freedesktop.appearance via the portal).
  - `src/plugins/platformthemes/CMakeLists.txt`: builds the two theme plugins.
  - `src/plugins/styles/{modernwindows,android,mac,ohos}/`: built-in style plugins (qLoadPlugin keys ship as JSON metadata).
  - `src/gui/platform/unix/qgenericunixtheme.cpp`: generic Unix theme base; QGnomeTheme is defined there (see QB2.3 and the gtk3 header).
- QB1.3 Build: `CMakeLists.txt` at repo root with per-module CMake files; plugin directories carry their own `CMakeLists.txt` (`src/plugins/platformthemes/gtk3/CMakeLists.txt`, `src/plugins/platformthemes/xdgdesktopportal/CMakeLists.txt`). Dependencies of the gtk3 plugin (GTK 3 headers/libs) are declared in its CMakeLists.txt; UNVERIFIED: exact target names not re-read.

## 2. Theme input (how configuration reaches it)
- QB2.1 Environment variable `QT_QPA_PLATFORMTHEME`: read at startup into `platformThemeName`. `src/gui/kernel/qguiapplication.cpp:1581`.
- QB2.2 Command-line flag `-platformtheme <name>` (also accepted in the Qt command-line parser): overwrites `platformThemeName`. `src/gui/kernel/qguiapplication.cpp:1607-1609`. The flag is consumed from argv (not passed to the platform plugin). Documented as overriding the env var at `src/gui/kernel/qguiapplication.cpp:544`.
- QB2.3 Environment variable `QT_STYLE_OVERRIDE`: read into `styleOverride` in `QApplicationPrivate::process_cmdline()` when not already set. `src/widgets/kernel/qapplication.cpp:363-364`. It is applied during QApplication init: `QStyleFactory::create(styleOverride.toLower())` then `QApplication::setStyle`; on failure, a warning lists `QStyleFactory::keys()` and the override is cleared. `src/widgets/kernel/qapplication.cpp:526-535`.
- QB2.4 The platform theme itself is not configured by a file in qtbase. Each theme plugin reads its own source:
  - gtk3: GTK 3 settings object (`gtk_settings_get_default`), connected to `gtk-application-prefer-dark-theme` and `gtk-theme-name` notifications. `src/plugins/platformthemes/gtk3/qgtk3theme.cpp:27`, `:91-103`. `gtk_init(nullptr, nullptr)` is called in the constructor. `src/plugins/platformthemes/gtk3/qgtk3theme.cpp:71`. Theme colours are resolved with `gtk_style_context_lookup_color` on a GtkStyleContext. `src/plugins/platformthemes/gtk3/qgtk3interface.cpp:397`. Current theme name read via `g_object_get(settings, "gtk-theme-name")`. `src/plugins/platformthemes/gtk3/qgtk3interface.cpp:489-491`.
  - xdgdesktopportal: D-Bus call `org.freedesktop.portal.Settings.ReadAll` on namespace `org.freedesktop.appearance`, and a `SettingChanged` signal subscription. `src/plugins/platformthemes/xdgdesktopportal/qxdgdesktopportaltheme.cpp:140-166` (call at 143-145, namespace list at 147). The key read is `color-scheme`. `src/plugins/platformthemes/xdgdesktopportal/qxdgdesktopportaltheme.cpp:24-25`, `:76-78`. Values map to Qt::ColorScheme. `src/plugins/platformthemes/xdgdesktopportal/qxdgdesktopportaltheme.cpp:60-63`.
- QB2.5 Flatpak/snap detection (selects the portal theme automatically): `QFileInfo::exists("/.flatpak-info")` or env `SNAP` set. `src/gui/kernel/qguiapplication.cpp:252-255`. Used at `src/gui/kernel/qguiapplication.cpp:1400`, which appends `xdgdesktopportal` to the candidate list.
- QB2.6 Plugin search path: `QFactoryLoader` for the theme loader is created with subpath `/platformthemes` and an extra search path from the `-platformpluginpath` argument. `src/gui/kernel/qplatformthemefactory.cpp:20-21`, `:27`. The loader then scans `QCoreApplication::libraryPaths()` (which is where QT_PLUGIN_PATH and qt.conf apply) plus each `<path>/platformthemes`. `src/corelib/plugin/qfactoryloader.cpp:371-379`. UNVERIFIED: the exact library-path precedence of QT_PLUGIN_PATH was not re-read in corelib beyond these lines.
- QB2.7 Theme name resolution order in `init_platform()`: (1) env/argv `platformThemeName`; (2) `xdgdesktopportal` if flatpak/snap; (3) names returned by the platform integration `themeNames()`. Each candidate is tried first with `QPlatformThemeFactory::create` (plugin), then with `QPlatformIntegration::createPlatformTheme` (built into the QPA plugin). First success wins. `src/gui/kernel/qguiapplication.cpp:1323` (function), `:1393-1421` (candidate list and loop). Platform name `key` syntax is `plugin:param1:param2...`; the part before the first `:` selects the plugin and the rest is passed as paramList. `src/gui/kernel/qplatformthemefactory.cpp:25-27`.
- QB2.8 Style plugin search path: `QStyleFactory` uses `QFactoryLoader` with subpath `/styles` and IID `org.qt-project.Qt.QStyleFactoryInterface`. `src/widgets/styles/qstylefactory.cpp:20-21`, `src/widgets/styles/qstyleplugin.h:17`.
- QB2.9 Default style: `QApplicationPrivate::desktopStyleKey()` returns the first style in `themeHint(StyleNames)` that exists in `QStyleFactory::keys()` (case-insensitive). Test-only override env `QT_DESKTOP_STYLE_KEY` exists under `QT_BUILD_INTERNAL`. `src/widgets/kernel/qapplication.cpp:1419-1440` (env at 1421-1424; theme loop at 1429-1436). If none matches, the first working entry of `QStyleFactory::keys()` is used. `src/widgets/kernel/qapplication.cpp:938-945`.

## 3. Color and style model
- QB3.1 QPalette: a set of brushes indexed by ColorGroup x ColorRole. ColorGroup: Active, Disabled, Inactive (Normal = Active), plus Current/All pseudo-groups. `src/gui/kernel/qpalette.h:51`.
- QB3.2 ColorRole enumeration (values in declaration order): WindowText, Button, Light, Midlight, Dark, Mid, Text, BrightText, ButtonText, Base, Window, Shadow, Highlight, HighlightedText, Link, LinkVisited, AlternateBase, NoRole, ToolTipBase, ToolTipText, PlaceholderText, Accent; NColorRoles = Accent + 1. `src/gui/kernel/qpalette.h:53-62`. Accent is the last role in this repo; the accessor `accent()` is at `src/gui/kernel/qpalette.h:105`.
- QB3.3 QPalette constructors that take a base set of colours: `QPalette(const QColor &button)` at `src/gui/kernel/qpalette.cpp:572`; 7-colour constructor at `:618`; 2-colour at `:635`. Individual setters: `setColor` / `setBrush` at `src/gui/kernel/qpalette.h:72-76`, `src/gui/kernel/qpalette.cpp:784`.
- QB3.4 Platform theme palette slots (enum Palette): SystemPalette, ToolTipPalette, ToolButtonPalette, ButtonPalette, CheckBoxPalette, RadioButtonPalette, HeaderPalette, and per-widget palettes (ItemView, MessageBoxLabel, TabBar, Label, GroupBox, Menu, MenuBar, TextEdit, TextLineEdit, ComboBox). `src/gui/kernel/qplatformtheme.h:118` onward. Font slots are a separate Font enum; `font(Font)` at `src/gui/kernel/qplatformtheme.h:312`.
- QB3.5 Theme hints (enum ThemeHint) include CursorFlashTime, KeyboardInputInterval, ToolButtonStyle, ToolBarIconSize, SystemIconThemeName, SystemIconFallbackThemeName, IconThemeSearchPaths, StyleNames (line 69), WindowAutoPlacement, DialogButtonBoxLayout, and others. `src/gui/kernel/qplatformtheme.h:51-72`. `themeHint()` at `src/gui/kernel/qplatformtheme.h:314`. Default hints are `QPlatformTheme::defaultThemeHint`. `src/gui/kernel/qplatformtheme.cpp:610`.
- QB3.6 Default system palette (generic): `QPlatformTheme::palette(SystemPalette)` lazily calls `initializeSystemPalette()` and returns the cached pointer; non-system palette types return nullptr. `src/gui/kernel/qplatformtheme.cpp:512-520`.
- QB3.7 Fusion palette (used by QFusionStyle::standardPalette): `qt_fusionPalette()` in `src/gui/kernel/qplatformtheme.cpp:389`. Light/dark is decided by `theme->colorScheme() == Qt::ColorScheme::Dark` (`:391-393`). Colours: window text black or (240,240,240); background (239,239,239) or (50,50,50); light = background.lighter(150); mid = background.darker(130); midLight = mid.lighter(110); base white or background.darker(140); dark = background.darker(150); shadow = dark.darker(135); highlight fixed to (48,140,198); disabled text (190,190,190) or (130,130,130). `src/gui/kernel/qplatformtheme.cpp:395-420`. Disabled brushes set at `:421-425`.
- QB3.8 Shade derivation in the core: QColor::lighter / darker with factors 110, 130, 135, 140, 150 as above. No other mixing formula in the Fusion path. Placeholder is text colour with alpha 128. `src/gui/kernel/qplatformtheme.cpp:416-417`.
- QB3.9 Application palette assembly: `QGuiApplicationPrivate::basePalette()` returns `*platformTheme()->palette()` if present, else `Qt::gray`. `src/gui/kernel/qguiapplication.cpp:3770-3774`. `updatePalette()` applies `app_pal` or a default QPalette. `src/gui/kernel/qguiapplication.cpp:3703-3711`.
- QB3.10 Per-widget palettes from the theme: `QApplicationPrivate::initializeWidgetPalettesFromTheme()` iterates a fixed table of (className, QPlatformTheme::Palette) pairs (QToolButton, QAbstractButton, QCheckBox, QRadioButton, QHeaderView, QAbstractItemView, QMessageBoxLabel, QTabBar, QLabel, QGroupBox, QMenu, QMenuBar, QTextEdit, QTextControl, QLineEdit, QComboBox) and calls `QApplication::setPalette(*palette, className)` for each non-null result. `src/widgets/kernel/qapplication.cpp:1246-1279`. It is called at startup at `src/widgets/kernel/qapplication.cpp:479` and on theme change at `:1243`.
- QB3.11 Per-class palette storage: `QApplication::setPalette(palette, className)` runs `app_style->polish(polishedPalette)` and stores the result in `widgetPalettes` keyed by class name. `src/widgets/kernel/qapplication.cpp:1195-1212`.
- QB3.12 Colour scheme: `QPlatformTheme::colorScheme()` (virtual) returns Qt::ColorScheme (Light, Dark, Unknown); the Fusion palette and the gtk3 and portal themes use it. Used at `src/gui/kernel/qplatformtheme.cpp:391`; overridden by `src/plugins/platformthemes/gtk3/qgtk3theme.h:22` and `src/plugins/platformthemes/xdgdesktopportal/qxdgdesktopportaltheme.cpp:247`.
- QB3.13 gtk3 palette model: `QGtk3Storage` maps each (ColorGroup, ColorRole) to a source (a GTK CSS colour name or a derived mix). Macros `ADD_2`, `ADD_3`, `ADD_MIX` fill a `TargetBrush -> Source` map. `src/plugins/platformthemes/gtk3/qgtk3storage.cpp:513-525`, `:590-601`. Fallback palette `QGtk3Storage::standardPalette()` at `:161-173`. Cached per-type palette `QGtk3Storage::palette()` at `:184-210`.
- QB3.14 xdgdesktopportal model: palette and font return values delegated to the base theme; colour scheme from the portal. `src/plugins/platformthemes/xdgdesktopportal/qxdgdesktopportaltheme.cpp:229-247`. UNVERIFIED: which base class supplies the palette body was not read.

## 4. Output and rendering path
- QB4.1 Call chain for the application palette and style (in order):
  1. `QGuiApplicationPrivate::createPlatformIntegration()` (starts at `src/gui/kernel/qguiapplication.cpp:1531`) parses argv and calls `init_platform()`: `src/gui/kernel/qguiapplication.cpp:1323` (definition), `:1632` (call).
  2. `init_platform()` creates the theme (`QPlatformThemeFactory::create`, then `createPlatformTheme`): `src/gui/kernel/qguiapplication.cpp:1413-1421`.
  3. Style hints are refreshed from the theme: `QStyleHintsPrivate::get(...)->update(platformTheme())`: `src/gui/kernel/qguiapplication.cpp:1633`.
  4. `QApplication` init calls `initializeWidgetPalettesFromTheme()` and `initializeWidgetFontHash()`: `src/widgets/kernel/qapplication.cpp:479-481`.
  5. Style object is created: `QApplicationPrivate::desktopStyleKey()` then `QStyleFactory::create`: `src/widgets/kernel/qapplication.cpp:938`. If `QT_STYLE_OVERRIDE` is set, `QApplication::setStyle` replaces it: `src/widgets/kernel/qapplication.cpp:526-528`.

## 5. Extension and integration points
- QB5.1 Theme plugin interface: `class QPlatformThemePlugin` with pure virtual `QPlatformTheme *create(const QString &key, const QStringList &paramList)`. `src/gui/kernel/qplatformthemeplugin.h:27-34`. The plugin subclass is in `main.cpp` of each theme (gtk3 `src/plugins/platformthemes/gtk3/main.cpp:10-19`).
- QB5.2 Theme base class `QPlatformTheme` (virtual methods used by plugins): `palette()` (`qplatformtheme.h:310`), `font()` (`:312`), `themeHint()` (`:314`), `colorScheme()`, icon and pixmap hooks. Plugins override these, e.g. `QGtk3Theme : public QGnomeTheme` (`src/plugins/platformthemes/gtk3/qgtk3theme.h:14`).
- QB5.3 Platform-integration fallback: QPA plugins may return theme names (`themeNames()`) and build their own theme (`createPlatformTheme(name)`). `src/gui/kernel/qguiapplication.cpp:1400-1421`.
- QB5.4 Installation paths: theme plugins are installed under `<Qt plugins dir>/platformthemes/`, style plugins under `<Qt plugins dir>/styles/`. Plugin dirs are found through `QCoreApplication::libraryPaths()` (`src/corelib/plugin/qfactoryloader.cpp:371-379`). UNVERIFIED: the install prefix values are set by CMake/QLibraryInfo and were not read.
- QB5.5 ABI coupling: the theme plugin IID is versioned (`org.qt-project.Qt.QPA.QPlatformThemeFactoryInterface.5.1`, `src/gui/kernel/qplatformthemeplugin.h:25`). Style plugin IID is unversioned (`src/widgets/styles/qstyleplugin.h:17`). Plugins built against private headers (for example the gtk3 plugin derives from QGnomeTheme in `src/gui/platform/unix/qgenericunixtheme.cpp`) are tied to the Qt build; UNVERIFIED: whether the gtk3 plugin uses private headers in CMake (not read).
- QB5.6 Selection by environment: `QT_QPA_PLATFORMTHEME` (theme), `QT_STYLE_OVERRIDE` (widget style), `QT_QPA_PLATFORM` (QPA plugin, `src/gui/kernel/qguiapplication.cpp:1573-1576`), `QT_DESKTOP_STYLE_KEY` (test-only, under `QT_BUILD_INTERNAL`, `src/widgets/kernel/qapplication.cpp:1421-1424`).

## 7. Facts of note
- QB7.1 The `-platformtheme` command-line option is parsed in `createPlatformIntegration()` and removed from argv before the platform plugin is created (`src/gui/kernel/qguiapplication.cpp:1607-1609`; argv compaction in the same loop, through `:1630`).
- QB7.2 If the chosen style key is not a valid style, the style override is cleared with the comment "so it is not picked by Qt Quick Controls (QTBUG-100563)". `src/widgets/kernel/qapplication.cpp:533-534`.
- QB7.3 The theme loader is a Q_GLOBAL_STATIC with case-insensitive key matching (`src/gui/kernel/qplatformthemefactory.cpp:20-21`); the platform key is lowercased (`:26`).
- QB7.4 The Fusion fallback palette is recomputed from the colour scheme; it is not cached in qtbase code beyond QPlatformTheme's systemPalette cache (`src/gui/kernel/qplatformtheme.cpp:512-520`, `src/gui/kernel/qplatformtheme.cpp:389-395`).
- QB7.5 The gtk3 plugin's constructor calls `gtk_init` in-process, which resets the Xlib error handler; the code restores it (comment at `src/plugins/platformthemes/gtk3/qgtk3theme.cpp:66-71`).
- QB7.6 Flatpak/snap detection uses file and env presence only (`src/gui/kernel/qguiapplication.cpp:252-255`).
